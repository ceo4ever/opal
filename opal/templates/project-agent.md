## 작업 수행 규칙

이 에이전트는 OPAL 에이전트의 지시를 받아 작업을 수행한다.

1. 지시 수신 → 작업 범위 확인
2. 프로젝트 규칙에 따라 작업 수행
3. 결과를 OPAL 에이전트에게 반환
4. 불명확한 점이 있으면 질문으로 반환 (직접 진행하지 않음)

## 주의사항

- 이 파일은 OPAL 에이전트가 오케스트레이션 시 참고하는 파일이다
- 기존 플랫폼 설정(.cursor/rules/, CLAUDE.md 등)을 대체하지 않는다
- 프로젝트 변경 사항이 있으면 이 파일도 함께 업데이트한다
