# DONE.md 표준 템플릿

> 로드 시점: CLOSE 단계에서 DONE.md를 작성할 때
> 역할: 표준 CLOSE `DONE.md` 템플릿 SSOT + `## 회고적 학습 후보` 절 계약

---

이 문서가 표준 CLOSE `DONE.md` 템플릿의 SSOT다. 오케스트레이터 SKILL은 이 문서를 포인터로 가리키고 템플릿 본문을 복제하지 않는다. `opal/skills/opal-pilot-gc/references/done-template.md`는 경량 GC 파이프라인 전용 템플릿이며 이 계약의 적용 대상이 아니다.

---

### DONE.md 표준 템플릿

```markdown
# DONE: {태스크 제목}

## 결과

{무엇이 달라졌는지 서술. 유지된 기존 동작과 적용한 경계를 함께 적는다.}

## 변경 파일

- `{경로}`

## 검증

- {실행한 검증 명령과 결과}

## 회고적 학습 후보

{레포 루트 상대 POSIX 경로 1행 1건. 후보가 없으면 `없음` 한 줄.}

## 참고

{후속 조치·미처리 항목. 없으면 이 절을 생략한다.}
```

| 절 | 내용 |
|------|------|
| 결과 | 태스크가 바꾼 것과 유지한 것. 단계 진행 경위는 쓰지 않는다(`state.json` 소유). |
| 변경 파일 | 생성·수정·삭제 파일 경로 목록 |
| 검증 | 실행한 검증 명령과 결과. 시나리오 PASS/FAIL 원본은 `test-scenario.json`이 소유한다. |
| 회고적 학습 후보 | 아래 §회고적 학습 후보 계약 |
| 참고 | 후속 조치·미처리 항목 |

**[MUST] 수기 누적 이력 절을 만들지 않는다.** `변경이력`, `Changelog`, `history` 등 이름과 무관하게 DONE.md에 이력 표를 두지 않는다 — 이력은 git과 태스크 기록이 소유한다.

---

### 회고적 학습 후보 계약

워크트리 태스크는 실행 중 워크트리의 brain 파일을 직접 바꾸지 않는다. 회고적 brain 학습은 이 절에 후보를 선언하고, 실제 page 생성·갱신·생략 판정은 merge 후 허브 finalize가 수행한다.

- 후보 brain page 경로를 **레포 루트 상대 POSIX 경로로 1행 1건** 선언한다.
- 후보가 없으면 `없음` 한 줄만 쓴다.
- 경로 외 본문(page 내용·요약)을 이 절에 넣지 않는다.

**[MUST] 이 절의 선언 집합이 finalize 재진입 판정의 입력이다.**

- 선언 집합 `D` = 이 절에 선언된 page 경로 ∪ `{.opal/brain/index.md, .opal/brain/log.md, .opal/MEMORY.json}`
- 관측 집합 `S` = 미커밋 변경 경로 중 `.opal/brain/**` 또는 `.opal/MEMORY.json`에 해당하는 것
- `S ⊆ D`이면 finalize 재개를 허용한다. 아니면 차단한다.

선언하지 않은 brain 경로를 변경하면 finalize가 차단된다. 중단된 1차 실행이 남긴 미커밋 brain page는 이 절에 선언되어 있어야 재실행이 재개된다.
