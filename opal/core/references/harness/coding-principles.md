# Coding Principles — 헌법의 OPAL 단계별 적용

> **행동 원칙 자체는 `opal/core/PRINCIPLES.md`(헌법)가 SSOT다.**
> 이 문서는 헌법을 OPAL 4단계(TASK / PLAN / TEST-SCENARIO / EXECUTE)와 PM Gate 사후 검증에
> 적용하는 **단계별 체크리스트와 OPAL 고유 세부**만 정의한다. 원칙을 재서술하지 않는다.

---

## §1 TASK — 헌법 §1(Think Before Acting) 적용

체크:
- [ ] 각 요구사항이 검증 가능한 단위(무엇을 / 어디에 / 왜 / AC)로 분해되었는가
- [ ] 각 AC가 Pass/Fail 판정 가능한 문장으로 작성되었는가
- [ ] 모호한 사항을 추측이 아닌 소유자 확인으로 해소했는가

---

## §2 PLAN — 헌법 §2(Simplicity First) 적용

체크:
- [ ] 설계가 현재 요구사항만 해결하는가 (over-engineering 없음)
- [ ] 기존 패턴과의 일관성이 유지되는가
- [ ] 새 패턴 도입 시 중복되는 기존 패턴을 제거했는가
- [ ] PLAN이 TASK 범위를 초과하지 않는가

---

## §3 TEST-SCENARIO — 헌법 §4(Goal-Driven) 적용 · 희박 케이스 분류

검증 시나리오는 발생 가능성과 영향도를 기준으로 선정한다. (헌법: "No error handling for impossible scenarios")

| 발생 가능성 | 영향도 | 처리 |
|----------|--------|------|
| 높음 | 높음 | 시나리오 필수 (Golden Path) |
| 높음 | 낮음 | 시나리오 작성 |
| 낮음 | 높음 | 시나리오 작성 + 정당화 명시 |
| 낮음 | 낮음 | 시나리오 제외 또는 Known Issue 기록 |
| 불가능 | — | 작성 금지 (위반 시 PM Gate 문서검증 Fail) |

체크:
- [ ] 불가능한 케이스를 다루는 시나리오가 없는가
- [ ] 낮음/낮음 케이스가 무분별하게 추가되지 않았는가
- [ ] 낮음/높음 케이스에 정당화 근거가 명시되었는가
- [ ] TASK.md의 각 AC가 어느 시나리오(S-N)에 대응하는지 매핑 표가 작성되었는가
- [ ] 실데이터/실연동 검증 시나리오가 있는가 — 목업만으로 통과하지 않도록 (헌법 §4 "Don't fake it")

---

## §4 EXECUTE — 헌법 §3(Surgical) · §4(Goal-Driven) 적용

체크:
- [ ] PLAN.md에 명시된 파일만 변경되었는가
- [ ] 인접 코드를 개선 명목으로 수정하지 않았는가
- [ ] 사변적 추가가 없는가
- [ ] 불가능한 케이스 방어 분기가 없는가
- [ ] **지시된 실연동을 목업으로 대체하지 않았는가** — 대체 불가 시 BLOCKED 표면화 (헌법 §4)
- [ ] **완료 선언에 동작 증거(실행 출력/실응답)가 첨부되었는가** (헌법 §4 "Completion requires evidence")

---

## §5 PM Gate — 사후 검증

> 문서 QA(요구사항→설계 검토)는 별도 QA Gate 단계 없이 PM Gate가 직접 흡수한다. 아래 체크리스트는 PM이 PM Gate 사후 검증에서 수행한다. 단, **동작 증거 항목(아래 마지막 3개)은 동작 검증(TEST / TEST-SCENARIO / state-tool verify, 독립·불변 영역)의 실행 결과로 입증되며 PM이 그 증거를 확인한다** — "글자 존재"로 대체 불가.

- [ ] 불필요한 추상화 레이어가 추가되지 않았는가 (헌법 §2)
- [ ] 현재 요구사항 범위를 초과한 구현이 없는가 (헌법 §2)
- [ ] PLAN.md 범위 밖 파일이 변경되지 않았는가 (헌법 §3)
- [ ] 인접 코드가 "개선" 명목으로 수정되지 않았는가 (헌법 §3)
- [ ] 모든 AC가 통과되었고, AC와 실제 구현 결과가 정확히 대응하는가 (헌법 §4)
- [ ] **AC 충족이 동작 증거로 입증되었는가 — "글자 존재"가 아닌 실행 결과로** (헌법 §4)
- [ ] **목업이 프로덕션 경로에 잔존하지 않는가** (헌법 §4)
