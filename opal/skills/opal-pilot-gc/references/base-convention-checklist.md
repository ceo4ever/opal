# Base Convention Checklist

> **[MUST] 프레임워크 내장 공통 컨벤션 기본값 포함 금지**
> 이 파일은 체크 카테고리와 감지 방식만 정의한다. 실제 규칙(예: 들여쓰기 2칸 vs 4칸)은
> 반드시 프로젝트 `docs/CONVENTIONS.md`에서만 로드한다.
> `docs/CONVENTIONS.md` 부재 시 → 체크 실패 아님. 초안 생성 유도로 전환.

---

## 카테고리 1: 네이밍

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 파일/폴더 네이밍 규칙 위반 | 파일명 패턴 매칭 (docs/CONVENTIONS.md §네이밍 규칙) | Y (리네이밍 — 단, import 체인 확인 필요) |
| 변수 케이스 일관성 위반 | 식별자 케이스 패턴 분석 | Y (단순 치환) |
| 함수/메서드 네이밍 규칙 위반 | 동사-명사 패턴 검사 | Y (단순 치환) |
| 컴포넌트/클래스 네이밍 접두사 규칙 | PascalCase vs kebab-case 불일치 | Y (단순 치환) |
| 상수 네이밍 규칙 위반 | UPPER_SNAKE_CASE 불일치 | Y |

## 카테고리 2: 들여쓰기

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 탭 vs 스페이스 혼용 | 탭 문자(`\t`) + 스페이스 혼재 탐지 | Y (통일) |
| 들여쓰기 깊이 일관성 | 파일 내 들여쓰기 크기 변동 감지 | Y |
| 파일 말미 개행 누락 | EOF `\n` 확인 | Y |
| 줄 끝 공백 | 행 끝 trailing whitespace | Y |

## 카테고리 3: 파일 구조

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 디렉토리 레이아웃 위반 | docs/CONVENTIONS.md §파일 구조 기준 비교 | N |
| 파일 길이 초과 (줄 수 제한) | 행 수 카운트 | N (분리 제안) |
| 순환 의존 | import 그래프 탐색 | N |
| 확장자 규칙 위반 | 파일 확장자 패턴 | N |

## 카테고리 4: 죽은 코드

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 미사용 함수/변수 | 정적 분석 — 참조 없는 export/정의 | Y (외부 참조 없는 경우만) |
| 주석 처리된 코드 블록 | `// .*code`, `/* ... */` 패턴 + 코드 특성 감지 | Y (주의: 외부 의존성 확인 필요) |
| 미참조 export | export 목록 vs import 참조 교차 검증 | N (외부 패키지 소비 가능성) |
| 사용되지 않는 인자 | 함수 파라미터 사용 여부 | N |

## 카테고리 5: 미사용 import

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 미사용 import 구문 | AST 분석 — import 후 미참조 | Y (제거) |
| 중복 import | 동일 모듈 다중 import | Y (병합) |
| 와일드카드 import | `import *` 패턴 | N (명시 import 제안) |

## 카테고리 6: 문서화

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 공개 함수 주석 누락 | export 함수 + 상위 JSDoc/docstring 없음 | N (작성 제안) |
| frontmatter 누락 (문서 파일) | .md 파일 YAML frontmatter 유무 | N |
| 변경이력 섹션 누락 | `## 변경이력` 또는 `## Changelog` 헤더 부재 | N |

## 카테고리 7: import 순서

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| 외부→내부→상대 경로 순서 위반 | 그룹별 순서 검사 | Y |
| 그룹 간 빈 줄 누락 | import 그룹 사이 빈 줄 확인 | Y |
| 알파벳 정렬 위반 (그룹 내) | 동일 그룹 내 알파벳 순서 | Y |

## 카테고리 8: 코드 품질 (getsentry/code-review 참조)

> **중요**: 이 카테고리는 프로젝트 CONVENTIONS.md에 관련 규칙이 없을 경우
> "위반"으로 판정하지 않고 **"추가 제안"으로만 표시**한다.
> getsentry/code-review는 참조 보조 자료이지 강제 기준이 아니다.

| 검사 항목 | 감지 방식 | 자동 수정 |
|---------|---------|---------|
| N+1 query 패턴 | 루프 내 DB 쿼리 호출 탐지 | N |
| O(n²) 알고리즘 패턴 | 중첩 루프 + 컬렉션 연산 패턴 | N |
| 불필요한 메모리 할당 | 루프 내 반복 객체 생성 패턴 | N |

## 초안 생성 시 제안 섹션 (docs/CONVENTIONS.md 부재 시)

`opal-convention-checker`가 CONVENTIONS.md 초안 생성을 제안할 때 포함 권장 섹션:

1. 네이밍 규칙 (파일/폴더/변수/함수/컴포넌트/상수)
2. 들여쓰기 및 포맷
3. 파일 구조 및 길이 제한
4. 죽은 코드 정책
5. import 순서 및 그룹화
6. 문서화 규칙 (JSDoc/docstring 적용 범위)
7. 코드 품질 가이드라인 (선택)

> 초안 생성 방식: `opal-project-init` 스킬 재사용 (Phase 2 작성 프로세스 + opi 소유자 승인 프로토콜 준수)
