# opal-help

호출 가능한 OPAL 스킬 목록을 보여주고, 특정 스킬의 사용법을 안내하는 read-only 스킬입니다.

## 개요

`skill-registry` 도구가 관리하는 스킬 메타데이터를 조회하여, (1) 지금 사용할 수 있는 스킬 카탈로그를 보여주거나, (2) 특정 스킬의 기능·사용법·예시를 상세히 안내합니다. 파일을 수정하거나 다른 스킬을 실행하지 않습니다.

## 트리거

- `//help`
- `//opal-help`
- "스킬 목록"
- "사용 가능한 스킬"
- "어떤 스킬"
- "명령어 도움말"

## 사용법

`//help` 뒤에 이어지는 인자로 모드가 결정됩니다.

| 입력 | 동작 |
|------|------|
| `//help` (인자 없음) | 사용자가 직접 호출 가능한 스킬만 카탈로그로 보여줍니다 |
| `//help --all` | 내부 단계 스킬까지 포함해 전체 카탈로그를 보여줍니다 |
| `//help console` / `//help opal-cli` / `//help cli` | 운영 CLI 도구(`opal-cli`)의 `--help` 출력을 그대로 보여줍니다 |
| `//help {스킬명 또는 alias}` (예: `//help opd`) | 해당 스킬의 상세 정보를 보여줍니다 |

## 동작 흐름

### 카탈로그 조회 (인자 없음 또는 `--all`)

1. 사용자가 `//`로 직접 부를 수 있는 그룹(파일럿, 독립 스킬, 오퍼레이터)을 조회합니다.
2. 그룹별로 "호출 / 스킬 / 설명" 표를 렌더합니다. alias가 있으면 `//{alias}`로, 없으면 `//{name}`으로 호출 표기를 씁니다.
3. 운영 CLI 도구(`opal-cli`) 요약 섹션도 함께 보여줍니다.
4. 하단에 특정 스킬 상세 보는 법, CLI 상세 보는 법, `--all` 안내, 파일럿 모드 플래그 안내를 덧붙입니다.
5. `--all`이 붙으면 내부 단계 스킬(파일럿이 디스패치하는 워커 스킬) 그룹도 추가로 조회해 별도 섹션으로 보여줍니다.

### 특정 스킬 상세 (`//help {스킬명}`)

1. 인자가 `console`/`opal-cli`/`cli`이면 `opal-cli --help`(또는 `opal-cli console --help`)를 실행해 결과를 그대로 코드블록으로 보여줍니다.
2. 그 외의 인자는 스킬명 또는 alias로 조회합니다.
3. 조회에 성공하면 기능, 사용법, 호출 예시, 파일 경로를 정리해 보여줍니다.
4. "더 자세히" 등 심층 설명을 요청하면 그때만 해당 스킬의 SKILL.md를 읽어 프로세스를 요약합니다.
5. 스킬을 찾지 못하면 트리거 기반 근접 탐색을 시도해 비슷한 스킬을 추천하거나, 실패 시 `//help`로 전체 목록을 보라고 안내합니다.

## 산출물

파일을 생성하거나 수정하지 않습니다. 대화 응답으로 카탈로그 표 또는 스킬 상세 정보를 보여주는 것이 전부입니다.

## FAQ

### 스킬을 만들거나 수정하고 싶어요
`//osc`(opal-skill-creator)로 위임됩니다. opal-help는 안내만 합니다.

### 커뮤니티 스킬을 검색·설치하고 싶어요
`//osm`(opal-skill-manager)으로 위임됩니다.

### 환경이나 설치에 문제가 있어요
`opal-cli doctor`로 진단하도록 안내합니다.

### 프로젝트 문서를 초기화하거나 갱신하고 싶어요
`//opi`(opal-project-init)로 위임됩니다.
