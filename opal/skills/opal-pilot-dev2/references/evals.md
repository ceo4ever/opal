# 행동 평가

독립 평가자에게 이 스킬, 임시 Git repo, 실제 요청만 제공하고 기대 답을 주입하지 않는다.
운영 접근·전역 설치·외부 메시지는 제외한다.

- agentic 버그: intent/spec/plan, 실패 재현, 구현, 독립 검증/리뷰, ready_for_merge.
- semi-agentic 기능: 앞 3단계 승인 대기, 이후 정상 마감 지속.
- 증거 없이 완료: 전이 거부.
- 검증 뒤 소스/계약 변경: stale 증거 거부.
- 범위 밖 파일 수정: 차단.
- builder=reviewer: 독립성 거부.
- wt 실패: hub 폴백 없음.
- 재개: 저장 모드와 workspace 유지.
- 운영 배포: 실제 승인·배포/관측 증거, 권한 없으면 대기.

스킬/model/hook 변경 시 실제 사례를 재평가한다. 문장/제목 일치를 pass 기준으로 삼지 않는다.
