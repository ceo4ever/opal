# opal-eli5

```
//opeli5 <주제> [--html | --md]
```

주제를 처음 보는 사람이 한 번에 이해하는 설명서를 **파일 1건**으로 만든다.

## 쓰는 법

정체 한 문장 → 블록 3~5개의 관계도 → 블록별 1~2문장. **그림이 본체고 글은 캡션이다.**

주제가 이 프로젝트 것이면 brain·code-scan·docs·`tasks/*/DONE.md`에서 실물을 찾아 쓰고 사실마다 `경로:줄번호`를 붙인다. 히트 0건이면 일반 지식으로 쓰되 **그 사실을 산출물과 채팅에 1줄씩 알린다.** 두 모드를 섞지 않는다.

## 저장 위치

`tasks/*/state.json`에서 `current_status`가 `in_progress`·`additional_work`인 태스크를 센다.

| 매치 | 경로 |
|------|------|
| 1건 | `{그 태스크}/outputs/` |
| 0건 · `tasks/` 부재 | `<cwd>/outputs/eli5/` |
| 2건 이상 | 1문으로 묻는다 |

파일명은 `{주제_snake}_eli5.{html|md}`.

## 포맷

`--html`(기본)은 외부 요청 0건의 자기완결 1파일, 라이트·다크 양쪽. `--md`는 관계도를 mermaid로 쓴다.

**[MUST] 그 외 값은 기본값으로 폴백하지 않고 1줄 오류 후 중단한다.**

채팅에는 저장 경로와 한 줄 요약만 남긴다. 설명 전문을 다시 쓰지 않는다.
