# opal-eli5

주제 하나를 처음 보는 사람도 한 번에 이해할 수 있도록, 그림 위주의 자기완결 설명 파일 1건으로 만들어주는 스킬입니다.

## 개요

복잡한 개념이나 이 프로젝트의 특정 구조를 "다섯 살에게 설명하듯" 쉽게 풀어줍니다. 정체를 한 문장으로 요약하고, 3~5개 블록으로 이루어진 관계도를 그림 위주로 보여준 뒤, 각 블록을 한두 문장의 짧은 캡션으로 설명합니다. 글보다 그림이 본체입니다.

주제가 이 프로젝트의 실제 구성 요소라면 brain, code-scan, 프로젝트 문서, 완료된 태스크 기록 등에서 실제 근거를 찾아 사실마다 출처(경로와 줄번호)를 붙입니다. 관련 근거를 전혀 찾지 못한 경우에는 일반 지식으로 설명하며, 이 경우 결과물과 대화 양쪽에 "일반 지식으로 작성했다"는 사실을 분명히 알립니다. 두 방식은 섞지 않습니다.

## 트리거

- `//opeli5` 또는 `//opal-eli5` 명시 호출

## 사용법

```
//opeli5 <주제>
//opeli5 <주제> --html
//opeli5 <주제> --md
```

- `--html`(기본값): 외부 요청이 전혀 없는 자기완결 단일 HTML 파일로, 라이트/다크 테마 양쪽에서 보기 좋게 만들어집니다.
- `--md`: 관계도를 mermaid 다이어그램으로 표현한 마크다운 파일로 만들어집니다.
- 이 두 값 외의 옵션을 주면 임의로 기본값으로 넘어가지 않고, 오류를 한 줄 알린 뒤 중단합니다.

## 동작 흐름

1. 주제를 받아, 이 프로젝트 내부에 관련 근거가 있는지 brain·code-scan·프로젝트 문서·완료된 태스크 기록에서 찾습니다.
2. 근거를 찾았으면 그 근거를 인용하며(경로:줄번호 포함) 설명을 구성하고, 못 찾았으면 일반 지식으로 설명하되 그 사실을 명시합니다.
3. 정체 한 문장 → 3~5개 블록의 관계도 → 블록별 짧은 캡션 순서로 자기완결 파일 1건을 만듭니다.
4. 저장 위치를 정합니다(아래 저장 위치 참고).
5. 완료 후에는 저장 경로와 한 줄 요약만 대화에 남기고, 설명 내용을 다시 채팅에 풀어 쓰지 않습니다.

## 저장 위치

`tasks/*/state.json`에서 진행 중(`in_progress`) 또는 추가 작업(`additional_work`) 상태인 태스크의 개수를 셉니다.

| 상황 | 저장 경로 |
|------|-----------|
| 진행 중인 태스크가 정확히 1건 | 그 태스크의 `outputs/` 폴더 |
| 진행 중인 태스크가 0건이거나 `tasks/` 폴더 자체가 없음 | 현재 위치의 `outputs/eli5/` 폴더 |
| 진행 중인 태스크가 2건 이상 | 어느 태스크에 저장할지 한 문장으로 되묻습니다 |

파일명은 `{주제_스네이크케이스}_eli5.html` 또는 `.md` 형식입니다.

## 산출물

- 위 저장 위치 규칙에 따른 폴더 안의 `{주제}_eli5.html`(또는 `.md`) 파일 1건.
- 다른 파일이나 부산물은 만들지 않습니다.

## FAQ

### 이 프로젝트와 무관한 일반 주제도 설명해 주나요?
네. 이 프로젝트 안에서 근거를 찾지 못하면 일반 지식으로 설명합니다. 다만 그 사실을 산출물과 대화에 반드시 표시합니다.

### 형식을 지정하지 않으면 어떻게 되나요?
기본값인 `--html`로 만들어집니다.

### 지원하지 않는 옵션을 주면 어떻게 되나요?
기본값으로 대신 처리하지 않고, 오류를 한 줄 알린 뒤 그 자리에서 멈춥니다.
