# opal-onboarding

OPAL 에이전트의 이름·호칭·톤·성격·역할을 인터뷰로 정의하는 초기 정체성 설정 스킬입니다.

## 개요

에이전트를 처음 사용할 때 `~/.opal/identity.md`가 없으면 자동으로 실행되어, 소유자와 단계별 인터뷰를 진행하고 그 결과로 `identity.md`를 생성합니다. 이후 세션에서는 이 파일을 통해 정해진 정체성으로 동작합니다.

## 트리거

- `//onboarding`
- "정체성 재설정"
- "온보딩 다시"
- `~/.opal/identity.md` 파일이 존재하지 않는 상태에서 부트스트랩이 진행될 때 자동 호출

## 사용법

별도 인자 없이 호출합니다.

| 호출 | 상황 |
|------|------|
| (자동) | `identity.md`가 없을 때 부트스트랩 과정에서 자동 실행 |
| `//onboarding` | 정체성을 다시 설정하고 싶을 때 수동 호출 |
| "정체성 재설정" / "온보딩 다시" | 자연어로 재설정 요청 |

## 동작 흐름

1. **환영 메시지**: OPAL을 소개하고 인터뷰 시작을 안내합니다.
2. **에이전트 이름** (주관식): 예) 오팔, 메듀사, 자비스, 프라이데이, 아이리스
3. **영문 별칭** (주관식): 짧은 영문 약어를 정합니다.
4. **소유자 호칭** (객관식 + 기타): 사용자/보스/사장님/대표님/선배님 중 선택하거나 직접 입력합니다.
5. **대화 톤** (객관식): 존댓말+친근 / 반말+직설 / 격식체 중 하나를 고릅니다.
6. **에이전트 성격** (객관식 복수 선택 + 기타): 꼼꼼함, 솔직함, 주도적, 유머러스, 차분함, 까칠함, 따뜻함 등에서 여러 개를 고를 수 있습니다.
7. **역할** (객관식 + 기타): AI 비서 / 개발 파트너 / 프로젝트 매니저 / 기술 컨설턴트 중 선택하거나 직접 입력합니다.
8. **추가 설정** (선택 주관식): 자유롭게 추가로 원하는 규칙이나 성격을 입력합니다(없으면 "없음").
9. **확인**: 수집한 정보를 요약해 보여주고, 수정 요청이 있으면 해당 단계로 돌아가 재질문합니다. 승인되면 다음 단계로 진행합니다.
10. **identity.md 생성**: `~/.opal/templates/identity-template.md`를 템플릿으로 사용해 수집한 정보로 `~/.opal/identity.md`를 만듭니다.
11. **프로젝트 부트스트래퍼 삽입**: 현재 프로젝트에서 다음 세션에도 에이전트가 자동 로드되도록 플랫폼별로 부트스트래퍼를 삽입합니다.
    - Claude Code: 프로젝트 루트 `CLAUDE.md`에 OPAL 마커 섹션을 추가하거나 갱신합니다.
    - Cursor: `~/.cursor/rules/000-opal-agent.mdc`가 이미 `alwaysApply: true`로 설정되어 있어 별도 작업이 필요 없습니다.
    - Antigravity: 프로젝트 루트 `GEMINI.md`에 동일한 방식으로 부트스트래퍼를 삽입합니다.

## 산출물

- `~/.opal/identity.md`: 에이전트 이름·별칭·호칭·톤·역할·성격을 담은 정체성 파일
- 프로젝트 루트의 `CLAUDE.md` 또는 `GEMINI.md`: OPAL 부트스트랩 섹션 추가/갱신 (Cursor는 해당 없음)

## FAQ

### 정체성을 다시 설정하고 싶어요
"정체성 재설정" 또는 "온보딩 다시"라고 요청하면 기존 `identity.md`를 `identity.md.bak`으로 백업한 뒤 이 스킬을 처음부터 다시 실행합니다.

### 인터뷰 중간에 답을 바꾸고 싶어요
확인 단계에서 수정할 부분을 말하면 해당 질문 단계로 돌아가 다시 물어봅니다.
