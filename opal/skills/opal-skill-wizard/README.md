# opal-skill-wizard

이 프로젝트에 딱 맞는 커뮤니티 스킬을 찾아서 안전성을 검사한 뒤, 승인한 것만 프로젝트 안에 설치해 주는 스킬입니다.

## 개요

"이런 작업을 자동화해줄 스킬 없을까?"라는 질문에 답하는 스킬입니다. 프로젝트의 기술 스택과 반복 작업을 파악한 뒤, 공개 스킬 카탈로그([skills.sh](https://skills.sh/))에서 후보를 검색하고, 각 후보를 보안 검사한 뒤 표로 제시합니다. 사용자가 승인한 스킬만 이 프로젝트 전용 폴더에 설치되고 등록됩니다.

이 스킬은 **프로젝트 범위 설치만** 담당합니다. 여러 프로젝트에서 공통으로 쓰는 전역 설치·삭제·업데이트는 다루지 않습니다(그 쪽은 `opal-skill-manager`가 담당합니다).

## 트리거

- `//osw` 또는 `//opal-skill-wizard` 명시 호출
- "프로젝트에 맞는 스킬 추천", "이 프로젝트에 쓸 스킬 찾아줘" 등의 발화

## 사용법

```
//osw
```

실행하려면 `.opal/` 디렉토리가 있는 프로젝트 루트(또는 그 하위)에서 호출해야 합니다. 프로젝트 루트를 찾지 못하면 아무 파일도 만들지 않고, 프로젝트 루트로 이동해서 다시 실행하라고 안내합니다.

## 동작 흐름

1. **환경 확인**: Node.js와 git이 설치되어 있는지, 보안 검사 도구가 있는지, 프로젝트 루트가 맞는지 차례로 확인합니다. 하나라도 안 되면 사유를 알리고 멈춥니다.
2. **컨텍스트 파악**:
   - `docs/PROJECT.md`가 이미 있으면 기술 스택과 폴더 구조를 그 문서에서 재사용하고, 자동화하고 싶은 작업 범주만 추가로 물어봅니다.
   - `docs/PROJECT.md`가 없으면 기술 영역, 반복 작업, 자동화 범주, 제약(라이선스·외부 네트워크 등) 네 가지를 짧게 인터뷰합니다.
3. **검색**: 수집한 정보로 검색어를 만들어 `npx skills find`로 카탈로그를 검색합니다. 결과가 여러 건이면 상위 3건만 다음 단계로 넘어갑니다. 검색 결과가 0건이면 곧바로 6단계(대안 안내)로 넘어갑니다.
4. **임시 확인 + 보안 검사**: 후보마다 임시 폴더에 내려받아 라이선스와 커밋 정보를 확인하고, 보안 검사 도구(`scan-risk`)로 위험도를 4단계(안전/주의/위험/미확인)로 판정합니다.
   - **위험** 판정을 받은 후보는 추천 목록에서 아예 제외됩니다.
   - **주의**나 **미확인** 판정을 받은 후보는 목록에는 오르되, 그 사실을 알리고 별도로 명시 승인을 받아야만 설치됩니다.
5. **제안 → 승인 → 설치**: 통과한 후보를 스킬명·출처·라이선스·보안 판정·설치 위치가 담긴 표로 제시합니다. 사용자가 승인한 스킬만 프로젝트 폴더로 복사되어 실제로 설치됩니다.
6. **적합한 후보가 없을 때**: 검색 결과가 0건이거나, 보안 검사를 통과한 후보가 하나도 없거나, 사용자가 제안된 후보를 모두 거절하면, 새 스킬을 만들어 주는 `opal-skill-creator`로 안내합니다. 이 경우 아무 파일도 만들지 않습니다.

## 산출물

- 설치가 이뤄진 경우:
  - `{프로젝트}/.opal/community-skills/{제공자}/{스킬명}/` 아래에 실제 스킬 파일 복사본
  - `{프로젝트}/.opal/skills-registry.json`에 설치 이력 등록(스킬명, 출처, 커밋, 라이선스, 보안 판정, 설치 시각 포함)
- 설치가 이뤄지지 않은 경우(전건 거절, 후보 없음, 프로젝트 루트 미확인 등): 아무 파일도 생성되지 않습니다.

## FAQ

### 검색된 스킬이 안전한지 어떻게 알 수 있나요?
후보마다 자동 보안 검사를 거쳐 안전/주의/위험/미확인 4단계로 판정합니다. 위험으로 판정된 후보는 애초에 추천 목록에 오르지 않으며, 주의나 미확인 후보는 그 사실을 알리고 별도로 확인을 받은 뒤에만 설치됩니다.

### 전역으로 설치하고 싶으면 어떻게 하나요?
이 스킬은 프로젝트 전용 설치만 담당합니다. 여러 프로젝트에서 공통으로 쓸 전역 설치는 `opal-skill-manager`를 이용해야 합니다.

### 원하는 스킬이 검색되지 않으면요?
검색 결과가 없거나 안전성 검사를 통과한 후보가 없으면, 새 스킬을 직접 만들어 주는 `opal-skill-creator`로 안내합니다.

### `docs/PROJECT.md`가 있으면 그 문서도 수정하나요?
아니요. 이 스킬은 `docs/PROJECT.md`를 읽기만 하고 수정하지 않습니다.
