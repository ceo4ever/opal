# EXECUTE 범용 에이전트 가이드

> 대상: opal-task-agent / 기타·미지정 에이전트
> 공통 절차: `references/execute-guide.md`

## 적용 차이

- 한 번의 디스패치에 배정된 W를 `선행 작업` 순서대로 수행한다.
- 같은 실행 그룹의 병렬화는 PM 책임이다. 범용 워커는 내부 서브에이전트를 호출하지 않는다.
- FE·BE·DB·문서가 섞여도 배정된 `변경 대상` 안에서만 수행하고, 파일 소유권이 충돌하면 블로커로 반환한다.
- PM이 주입한 `## 실행 capability`만 사용한다. 도메인별 스킬·MCP를 자체 탐색하지 않는다.

나머지 진입 검사, 구현, 검증, 상태 기록, 블로커, 결과 형식은 공통 가이드만 따른다.
