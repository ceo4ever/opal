# 요구서: stockctl 차감 정책 정비와 부족 알림

## 배경
영업팀과 회계팀이 각각 요청을 보냈다. 두 요청을 반영해 `remove`를 정비한다.

## 영업팀 요청
- 주문이 들어오면 재고가 부족해도 `remove`로 차감을 기록할 수 있어야 한다. 부족분은 음수 재고로 남겨 두었다가 입고 시 자동으로 상쇄되게 해 달라.

## 회계팀 요청
- 재고 수량은 실물과 일치해야 하므로 0 미만이 되면 안 된다. 현재 `docs/CLI.md`의 계약(수량 부족 시 exit 2)은 유지해야 한다.

## 공통 요구
- `stockctl low-stock --below N` 명령을 추가한다. 수량이 N 미만인 품목을 `SKU\tQTY` 줄로 출력하고 exit 0으로 끝난다.
- 기존 테스트는 계속 통과해야 하고 `docs/CLI.md`를 갱신한다.
