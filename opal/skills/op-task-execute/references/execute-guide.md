# EXECUTE 단계 상세 가이드 (범용)

이 가이드는 op-task-execute 스킬에서 참조된다. 도메인 무관 범용 태스크에서 사용한다.

> **실행 컨텍스트**: 이 가이드는 워커 에이전트의 컨텍스트에서 실행된다.
> 오케스트레이터가 워커를 디스패치하면, 워커가 이 가이드를 읽고 프로세스를 따른다.

---

## 금지 행동 (EXECUTE 가드레일)

### 절대 금지

| # | 금지 행동 | 이유 |
|---|----------|------|
| 1 | PLAN.md에 없는 파일 생성/수정 | 계획 밖 변경은 추적 불가, 회귀 리스크 |
| 2 | PLAN에서 확정된 설계를 임의로 변경 | QA를 통과한 설계를 무효화 |

### 판단 기준: 즉시 멈추고 보고 vs 진행 후 보고

**즉시 멈추고 보고 (블로커 처리)**:
- PLAN의 설계와 실제 파일 간 구조적 불일치 발견
- 필요한 외부 리소스/시스템이 접근 불가
- 예상과 다른 파일 구조로 인해 3개 이상 Step에 영향
- PLAN에 명시되지 않은 파일을 생성/수정해야 하는 상황

**진행 후 보고 (완료 보고에 포함)**:
- 사소한 포맷/스타일 조정
- 내용 조정 (핵심 구조 변경 없이)
- 오타 수정

## 실행 규칙

### 순차 실행

op-execute는 항상 순차 direct 실행이다. 병렬 실행 없음.

```
Step 1 → Step 2 → ... → Step N → QA 체크리스트 → 결과 반환
```

### Step별 실행 절차

각 Step을 실행할 때:

1. **대상 확인**: 대상 파일이 이미 존재하면 Read로 현재 내용 파악
2. **실행**: Write/Edit로 파일 작성/수정 (또는 Bash로 삭제/이동)
3. **검증**: Step의 완료 기준에 따라 결과 확인
4. **체크박스 갱신**: PLAN.md 체크박스 즉시 업데이트

### 기존 파일 수정 시

기존 파일을 수정할 때는 **반드시 먼저 Read로 현재 내용을 확인**한다. 추측으로 덮어쓰지 않는다.

---

## 체크리스트 갱신 규칙

### 실행 체크리스트 갱신

EXECUTE 중 각 Step 완료 시 즉시 체크박스를 갱신한다.

PLAN.md 실행 체크리스트(섹션 3)의 각 Step:
- `- [ ] 완료` → `- [x] 완료`

### QA 체크리스트 갱신

모든 실행 Step 완료 후, QA 체크리스트를 검증하고 갱신한다.

**대상**: PLAN.md 섹션 4 QA 체크리스트

**절차**:
1. QA 체크리스트의 각 항목을 실제로 검증
2. 통과한 항목: `- [ ]` → `- [x]`
3. 미통과 항목: `- [ ]` 유지 + 사유를 인라인 주석으로 기록

---

## 블로커 처리

블로커가 발생하면:

1. **즉시 중단** — 추측으로 해결하지 않는다
2. **사용자 보고**:
   - Step 번호와 제목
   - 구체적 상황/오류
   - 가능한 원인
   - 해결 방안 제안
3. **사용자 지시 대기** — 지시에 따라 재개 또는 건너뛰기

- [ ] 각 Step의 완료 기준이 통과되었는가?
- [ ] 블로커 발생 시 사용자에게 보고되었는가?
- [ ] 변경 파일 목록이 PLAN.md의 파일 목록과 일치하는가?
- [ ] QA 체크리스트 체크박스가 갱신되었는가?
- [ ] PLAN.md에 없는 파일을 생성/수정하지 않았는가?
