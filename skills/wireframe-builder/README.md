# wireframe-builder (wfb)

정책서·요구사항 문서를 분석해 화면 구조를 도출하고, 구조화된 `wireframe.md`를 생성하는 UI 분석·설계 스킬.

## 개요

정책서, 요구사항 문서, 화면 스크린샷, 손 스케치 등을 입력받아 필요한 화면을 도출하고, 화면별 레이아웃·구성 요소·인터랙션을 구조화된 Markdown 문서(`wireframe.md`)로 정리합니다. 이 문서는 그 자체로 화면 설계 산출물이며, 후속으로 `ui-designer` 스킬에 전달하면 React + shadcn/ui 기반 실제 UI로 구현됩니다.

```
파이프라인: wireframe-builder → wireframe.md → ui-designer → UI
```

> 과거에는 HTML 와이어프레임을 직접 생성했으나, 그 기능은 `ui-designer` 스킬로 이관되었습니다. 이 스킬은 화면 구조 "설계"까지만 담당합니다.

## 언제 쓰나

- "와이어프레임", "화면 설계", "UI 설계", "화면 구조", "화면 도출" 요청을 받았을 때
- 정책서/기획서를 바탕으로 필요한 화면을 도출해야 할 때
- 기존 화면 스크린샷이나 손 스케치를 구조화된 설계 문서로 정리해야 할 때

## 사용법

호출: `//wfb`

| 입력 유형 | 형식 | 설명 |
|------|------|------|
| 문서 | `.md`, `.txt`, `.pdf` | 정책서, 요구사항 문서 — 직접 읽기 |
| 문서 | `.docx` | Word 문서 — docx 스킬 연계 |
| 이미지 | `.png`, `.jpg` 등 | 기존 화면 스크린샷, 손 스케치, Figma 목업 등 |
| 텍스트 | 인라인 | 채팅에 직접 입력한 요구사항 |
| 혼합 | 파일 + 설명 | 문서/이미지 + 추가 컨텍스트 텍스트 |

최소한 서비스 목적, 핵심 기능/엔티티 1개 이상, 대상 사용자/역할 정보가 있어야 설계를 시작하며, 부족하면 `interview` 스킬로 보완합니다.

이미지를 입력하는 경우 유형에 따라 분석 방향이 다릅니다: 기존 화면 스크린샷은 레이아웃을 역공학해 개선된 구조로, 손 스케치는 구조 해석 후 형식화, Figma/목업 이미지는 디자인 분석 후 shadcn 컴포넌트로 매핑, 경쟁사 UI는 레이아웃 패턴 참조로 처리합니다.

## 동작 흐름

1. **입력 분석**: 핵심 기능, 엔티티, 사용자 역할, 비즈니스 규칙을 식별하고 서비스 유형(관리자 대시보드/SaaS/공개 웹사이트/모바일 앱 등)을 판별합니다. 부족하면 인터뷰로 보완합니다.
2. **화면 도출**: 도출 규칙 테이블(예: 엔티티 CRUD 요구 → 관리 페이지, 대시보드 요구 → dashboard 화면)을 적용해 필요한 화면을 식별하고, 각 화면에 ID(`SCR-NNN`)·유형·경로·메뉴그룹을 부여한 뒤 화면 간 네비게이션 흐름을 정의합니다.
3. **화면별 상세 설계**: 화면 유형(dashboard/crud/detail/form/settings/report/auth/monitor)에 맞는 ASCII 레이아웃을 적용하고, 영역·UI 요소·shadcn 컴포넌트·데이터를 매핑한 구성 요소 테이블과 인터랙션 목록을 작성합니다.
4. **산출물 생성**: 위 내용을 `wireframe.md` 스키마에 맞춰 통합합니다.

화면 수가 5개 이상이면 화면별 상세 설계(3단계)를 서브 에이전트에 분배하고, 메인 에이전트가 입력 분석·화면 도출·최종 통합을 담당합니다.

## 산출물

`{태스크 폴더}/wireframe.md` (또는 사용자 지정 경로)에 아래 구조로 생성됩니다.

| 섹션 | 내용 |
|------|------|
| 헤더 | 서비스명, 작성일, 버전 |
| 1. 서비스 개요 | 서비스명, 유형, 대상 사용자, 핵심 기능 목록 |
| 2. 전체 구조 | 레이아웃 유형, 네비게이션 구조, 화면 흐름도 |
| 3. 화면 목록 | ID·화면명·유형·경로·메뉴그룹·설명 마스터 테이블 |
| 4. 화면별 상세 설계 | 화면마다 메타 정보, ASCII 레이아웃, 구성 요소 테이블, 기능, 인터랙션 목록 |
| 5. 공통 컴포넌트 | 재사용 컴포넌트와 사용 화면 |
| 6. shadcn 설치 목록 | 필요한 shadcn 컴포넌트와 설치 명령 |

이 문서를 `ui-designer` 스킬에 전달하면 실제 화면(프로토타입 또는 프로덕션 코드)이 생성됩니다.
