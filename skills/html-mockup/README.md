# html-mockup (mockup)

CDN 스택만으로 빌드 없이 바로 브라우저에서 열리는 정적 HTML 화면을 빠르게 만드는 스킬.

## 개요

빌드 과정 없이 CDN 기반 정적 HTML로 화면 1~수개를 빠르게 생성합니다. 실제 인터랙션이 필요한 프로토타입(`ui-designer` 스킬 담당)과 구분되는, "검토용 정적 화면"을 만드는 것이 목적입니다. 태스크 폴더나 프로젝트 문서가 있으면 자동으로 컨텍스트를 흡수해 필요한 질문 수를 줄이고, 부족한 정보만 `interview` 스킬로 보완합니다. OPAL 프로젝트 여부와 무관하게 어디서든 동작합니다.

## 언제 쓰나

- "화면 만들어줘", "목업 만들어줘", "HTML로 빠르게 보여줘" 요청을 받았을 때
- 와이어프레임 검토용으로 빠르게 확인 가능한 정적 화면이 필요할 때

## 사용법

호출: `//html-mockup` 또는 `//mockup`

| 항목 | 내용 |
|------|------|
| 필수 입력 | 저장 위치 (인터뷰로 확인) |
| 보장 출력 | HTML 화면 파일 + `shared/` 폴더 + (화면 2개 이상 시) `index.html` |

인터뷰는 최대 7개 노드를 한 번에 1문씩 진행하며, 컨텍스트로 추론 가능한 항목은 자동 스킵됩니다.

| # | 질문 | 옵션 |
|---|------|------|
| 1 | 저장 위치 (필수, 스킵 불가) | 현재 태스크 폴더의 `mockup/` / 현재 cwd 직속 `mockup/` / 직접 입력 |
| 2 | 화면 종류·개수 | 자유 입력 |
| 3 | 핵심 액션·데이터 | 자유 입력(선택) |
| 4 | 분리 모드 | 화면별 분리(기본) / 단일 파일에 섹션으로 묶기 |
| 5 | UI 라이브러리 | DaisyUI(기본 추천) / Flowbite / Tailwind만 |
| 6 | 다크모드 | 아니오(기본) / 예(DaisyUI 테마 토글) |
| 7 | 입력 자원 | 참고할 이미지·Figma URL·참고 사이트(선택) |

와이어프레임 이미지, Figma URL, 참고 사이트 URL을 함께 주면 레이아웃·컴포넌트를 분석해 반영합니다.

## 동작 흐름

1. **환경 감지**: `.opal/AGENT.md`, `tasks/{NNN}-*/TASK.md`, `STATE.md`/`MEMORY.json` 존재 여부로 OPAL 프로젝트·태스크 폴더 여부를 판별합니다.
2. **컨텍스트 흡수**: 감지 결과에 따라 `TASK.md`/`ANALYSIS.md`/`PLAN.md` 또는 `STATE.md`/`MEMORY.json`을 읽어 화면 종류, 핵심 데이터 등을 추론합니다.
3. **인터뷰**: 위 7개 노드를 진행하되 추론 가능한 항목은 스킵합니다.
4. **입력 자원 처리**: 이미지·URL이 있으면 레이아웃/구조를 분석해 반영합니다.
5. **산출물 생성**: `templates/boilerplate.html`의 `{{TITLE}}`/`{{BODY}}`/`{{NAV}}`/`{{EXTRA_HEAD}}` 토큰을 채워 화면마다 HTML을 생성하고, `templates/shared/`(style.css, main.js)를 저장 위치에 복사합니다. 화면이 2개 이상이면 `templates/index.html.tmpl` 기반 인덱스 페이지를 자동 생성합니다.
6. **보고**: 생성/수정 결과를 안내합니다.

## 산출물

```
{저장위치}/
├── index.html           ← 화면 인덱스 (2개 이상일 때만 자동 생성)
├── login.html
├── dashboard.html
└── shared/
    ├── style.css        ← 공통 스타일 (Pretendard 폰트 등)
    └── main.js          ← 공통 JS (Lucide 아이콘 초기화, Alpine store)
```

각 HTML 파일은 아래 CDN 스택으로 구성되며 빌드 없이 브라우저에서 바로 열립니다.

| 라이브러리 | 역할 |
|-----------|------|
| Pretendard | 한글 폰트 |
| Tailwind CSS | 유틸리티 CSS |
| DaisyUI | UI 컴포넌트 |
| Alpine.js | 선언적 인터랙션 |
| Lucide | SVG 아이콘 |

화면명은 자동으로 kebab-case 파일명으로 변환됩니다(예: "My Dashboard" → `my-dashboard.html`). 한글 화면명은 AI가 의미 기반 영문명을 제안하고 확인을 받습니다(발음 로마자 변환은 사용하지 않습니다).

## FAQ

### 기존 파일과 이름이 겹치면 어떻게 되나요?
같은 호출 안에서 "수정"/"바꿔줘" 등의 키워드가 있으면 자동 덮어쓰기하고, 새 호출에서 충돌이 나면 덮어쓸지·다른 이름으로 저장할지 확인을 받습니다. `index.html`은 항상 자동 덮어씁니다.

### CHANGELOG나 백업 파일이 생기나요?
아니요. 변경이력 파일, 백업 파일, 버전 suffix는 생성하지 않습니다.

### 목업과 프로토타입의 차이는 무엇인가요?
목업은 이 스킬이 만드는 빠른 검토용 정적 HTML이고, 실제 인터랙션이 동작하는 프로토타입은 `ui-designer` 스킬이 담당합니다.
