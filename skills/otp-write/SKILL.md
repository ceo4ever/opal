# 범용 문서 작성 오케스트레이터

## 파이프라인

```
dtp-task → 소스 조사 + 목차 설계 → [QA] → 검토/승인
  → 섹션별 작성 → opal-doc-standard 적용 → 완료
```

---

## 커버 범위

**가능한 문서 유형**:
- 기술 프로젝트 산출물: PRD, TRD, IA, ERD, 정책서, API 명세서, 설계서
- 보고서: 기술 분석, 비즈니스 분석, 상태 보고서
- 가이드/매뉴얼: 사용자 매뉴얼, 온보딩 가이드, 운영 가이드
- 기획/제안: 제안서, 기획서, RFP 응답
- 내부 커뮤니케이션: 회의록, FAQ, 내부 공지

**otp-write가 아닌 것**:
- 코드 구현 수반 -> otp-dev / otp-dev-short
- 프로젝트 전체 파일럿 -> opdp
- 와이어프레임/UI 설계 -> otp-wf
- 외부 API 분석 -> api-analyzer

---

## STEP 1: TASK (직접 수행)

오케스트레이터가 **직접 수행**한다.

1. `dtp-task/SKILL.md`를 Read한다.
   - 탐색: `{프로젝트}/.opal/skills/dtp-task/SKILL.md` -> `~/.opal/skills/dtp-task/SKILL.md`
2. 스킬 프로세스를 따라 TASK.md를 작성한다.
   - 작업 유형은 "문서 작성"
   - 추가 확인: 문서 유형, 대상 독자, 범위, 출력 형식(.md/.docx/.pdf)
3. STATE.md를 생성한다.
4. 사용자에게 보고

```
📋 [TASK] 완료 보고
📎 산출물: tasks/{NNN}-{태스크명}/TASK.md
다음 단계(PLAN)로 넘어갈까요?
```

---

## STEP 2: PLAN (직접 수행)

오케스트레이터가 **직접 수행**한다.

### 소스 조사 (문서 유형별 분기)

| 문서 유형 | 소스 조사 방식 |
|-----------|-------------|
| 기술 산출물 (설계서, 명세서, ERD 등) | Glob/Grep/Read로 코드베이스 분석 |
| 보고서 | 코드 분석 + WebSearch로 외부 정보 |
| 가이드/매뉴얼 | 코드 분석 + 기존 문서 참조 |
| 기획/제안 | WebSearch + interview 스킬 활용 |
| 내부 커뮤니케이션 | 기존 문서/데이터 참조 |

### 목차 + 구조 설계

1. `~/.opal/references/opal-doc-standard.md`를 Read하여 문서 표준 적용
2. 문서 유형에 맞는 필수 섹션 구성
3. 각 섹션별 핵심 내용 개요 정의
4. PLAN.md로 작성 (목차 + 섹션별 개요 + 참조 소스 목록)

### QA (선택)

복잡한 문서의 경우 dtp-qa 워커 호출. 단순 문서는 스킵.

### 사용자 보고

PLAN(목차/구조)을 사용자에게 제시. **승인 = WRITE 시작 허가**.

```
📋 [PLAN] 완료 보고
📎 산출물: tasks/{NNN}-{태스크명}/PLAN.md
목차와 구조를 확인해 주세요. 승인 시 작성을 시작합니다.
```

---

## STEP 3: WRITE (직접 수행)

오케스트레이터가 **직접 수행**한다.

1. PLAN.md의 목차에 따라 섹션별 순차 작성
2. opal-doc-standard 규칙 적용 (언어, 헤더, 테이블, 버전)
3. 출력 형식 처리:
   - `.md`: 기본 (직접 Write)
   - `.docx`: `anthropics/docx` 커뮤니티 스킬 Read 후 연동
   - `.pdf`: `anthropics/pdf` 커뮤니티 스킬 Read 후 연동
4. 사용자에게 완성본 제시
5. DONE.md 생성

### 커밋 규칙

**커밋은 사용자가 명시적으로 요청할 때만 수행한다.** 완료 보고만 하고 사용자 지시를 기다린다.

## STATE.md 관리

```markdown
# STATE: {문서 제목}

> 최종 갱신: YYYY-MM-DD HH:mm

## 현재 상태
- 모드: 문서 작성
- 단계: {TASK / PLAN / WRITE}
- 상태: {진행 중 / 대기 중 / 완료}

## 완료 산출물
| 산출물 | 상태 |
|--------|------|
| TASK.md | {완료 / 미생성} |
| PLAN.md | {완료 / 미생성} |
| {문서명} | {완료 / 미생성} |
| DONE.md | {완료 / 미생성} |

## 다음 액션
{다음으로 수행할 작업}
```
