현행 / 진행 / 후순위

프레임워크 본체는 아키텍처 안정화 단계. 아래는 배포·관측 영역의 빌드 우선순위다 — 미루는 것을 명시하는 것도 초점의 일부.

  • 부트스트랩·하네스·Pilot 9·에이전트 13 동작 중
  • GitHub Releases · opal-cli · one-liner installer

  • Project Brain + Data Design 파이프라인 내재화
▶ 진행 — 확장 중

관측 + 2차

  • OPAL Console 쓰기/편집 화면 (현재 read-only)
  • Console brain 화면
  • Homebrew tap — brew install opal-cli
  • code-scan @header 커버리지 확충
▶ 후순위 — 미룰 것
