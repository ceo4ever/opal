OPAL
— Open Protocol for Agentic Loops

AI 플랫폼 위에서 IT 프로젝트를 수행하는 범용 에이전트 프레임워크. 플랫폼 부트스트랩 진입부터 멀티플랫폼 배포까지 10개 계층으로 동작한다. 위에서 아래로 읽으면 하나의 요청이 흐르는 하강 흐름이고, 맨 아래 환류 밴드는 CLOSE에서 적재된 지식이 L3로 되돌아오는 귀환 경로다.

코드맵 (Code Map) CORE
what
코드 구조·exports·depends의 전수·실시간 사실. SSOT는 파일 @header(인라인) 또는 .opal/code-map/ 매니페스트이며, 기록 소스는 .opal/code-scan.json 전역 headerSource(inline|manifest) 단일 키가 결정한다(미설정 시 전 명령 차단). 관리 도구는 code-scan.

brain (Project Brain) 안정
why · how
설계 배경·과거 결정의 선별·stale 가능 스냅샷. SSOT는 .opal/brain/(index + 페이지)이며 //opbr init으로 생성되는 프로젝트 자산이다. 관리 도구는 brain-tool. search 후보 목록 → 상위 선별 → 선택 페이지만 주입(전량 로드 금지).
brain-tool · 10서브명령.opal/brain/참조 시점 — 설계 착수 전 3시점
MEMORY (프로젝트 메모리) 안정
운영 기억 · 임시
히스토리·피드백·선호·결정. 임시 보관소이며 성숙한 지식은 promote로 docs/brain 영구 거처에 졸업한다. SSOT는 .opal/MEMORY.json(인덱스) + memory/*.md(본문)이고 변경은 memory-tool만 수행한다.
