# 디스패치 프롬프트의 외부 CLI 플래그는 실측으로 확인하고 적는다

- 유형: improvement
- 상태: candidate
- 기록일: 2026-09-19
- 출처: 태스크 145

## 내용

태스크 145에서 PM이 워커 프롬프트에 `orca terminal read --scrollback/--lines`를 사용하라고 적었지만 실제 공개 플래그는 `--limit`이었다. 실측하지 않은 외부 CLI 계약을 단정형으로 전달하면 워커가 잘못된 지시를 그대로 구현하거나 검증할 위험이 있다.

외부 CLI 플래그·응답 스키마·파일 앵커는 도움말이나 실제 호출로 확인한 뒤 프롬프트에 적는다. 미확인 항목은 추정임을 표시하고 워커가 실측으로 확정하도록 요구한다.

## 본문 복구 경위

`improve-tool record --scope local`이 MEMORY 인덱스 행만 만들고 본문 파일을 생성하지 않은 알려진 결함 때문에 누락된 파일을 태스크 145의 회고 기록과 인덱스 요약을 근거로 복구했다.
