# 날짜 vs 일시 표기 기준

> 등록일시: 2026-03-30 14:30 | 카테고리: feedback | 상태: 유효

## 규칙

날짜 표기는 용도에 따라 구분한다:

- **일자(`YYYY-MM-DD`)**: 단순 일별 조회 용도. 정확한 시점이 중요하지 않은 경우.
  - 예: 프로젝트 생성일, 문서 작성일, identity.md created_at
- **일시(`YYYY-MM-DD HH:mm`, KST)**: 정확한 시점 추적이 필요한 경우.
  - 예: 변경이력, 작업 히스토리(시작/완료), 메모리 등록일시, STATE.md 갱신

**Why:** "만들어진, 수정된 정확한 시점을 알고 싶은 부분에는 일시를 작성해줘" — 캡틴 피드백

**How to apply:** 새 필드를 만들 때 "이 값의 정확한 시점이 의미 있는가?"를 판단. 시점이 중요하면 일시, 아니면 일자.
