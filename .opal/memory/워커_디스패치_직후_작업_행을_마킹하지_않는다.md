# 워커 디스패치 직후 작업 행을 마킹하지 않는다

- 유형: improvement
- 상태: candidate
- 기록일: 2026-09-19
- 출처: 태스크 145

## 내용

태스크 145에서 PLAN 워커를 디스패치한 직후 비동기 작업이 끝나기 전에 관련 행을 완료로 마킹했다. 워커 결과와 증거를 아직 받지 않은 시점의 완료 표시는 실제 진행 상태와 현황판을 어긋나게 한다.

작업 행은 워커의 종료와 산출물·검증 결과를 확인한 뒤에만 완료로 전환한다. 비동기 디스패치 직후에는 진행 중 상태를 유지하고, 워커 결과 수신 전에는 다음 행을 완료 처리하지 않는다.

## 본문 복구 경위

`improve-tool record --scope local`이 MEMORY 인덱스 행만 만들고 본문 파일을 생성하지 않은 알려진 결함 때문에 누락된 파일을 태스크 145의 회고 기록과 인덱스 요약을 근거로 복구했다.
