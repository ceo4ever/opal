# 비차단 보고 후 턴을 끝내지 않는다

- 유형: improvement
- 상태: candidate
- 기록일: 2026-09-19
- 출처: 태스크 145

## 내용

agentic 모드에서 `state-tool`이 `transition_action=continue`와 `report_type=progress_report`를 반환했는데도 진행 보고 직후 턴을 종료했다. 이 응답은 사용자 결정을 기다리는 경계가 아니라 다음 파이프라인 행으로 계속 진행하라는 계약이다.

PM은 `await_user|blocked` 또는 `decision_request`일 때만 멈춘다. `continue + progress_report`에서는 보고를 남긴 뒤 같은 턴의 자율주행을 계속한다.

## 본문 복구 경위

`improve-tool record --scope local`이 MEMORY 인덱스 행만 만들고 본문 파일을 생성하지 않은 알려진 결함 때문에 누락된 파일을 태스크 145의 회고 기록과 인덱스 요약을 근거로 복구했다.
