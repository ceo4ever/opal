# 산출물 기반 강제 (Artifact Gate) 필요성

## 문제

알투(PM)가 하네스 프로세스(QA Gate → PM Gate 등)를 규칙으로 정의해도 실제로 빠뜨리는 일이 반복됨. 근본 원인은 "규칙 미준수"이며, LLM 특성상 컨텍스트에서 밀려나 의도 없이 스킵하는 구조적 문제.

## 해결 방향

규칙 준수를 "의지"가 아니라 "구조"로 강제한다:

1. **산출물 기반 강제 (Artifact Gate)**: QA Gate 완료 시 QA-PLAN.md 등 산출물 파일이 반드시 생성되어야 하고, 해당 파일이 없으면 다음 단계(PM Gate, DONE.md 생성 등) 진입 불가
2. **캡틴 가시성**: PM 모드 표시로 캡틴이 현재 단계를 알고, 스킵을 직접 잡을 수 있음
3. **게이트 체크리스트 프롬프트**: 게이트 진입 시 산출물 존재 여부를 출력하여 자가 점검

## 대응 태스크

별도 태스크로 Artifact Gate 설계 필요. 087(역할 전환 + 추가작업)과는 분리.
