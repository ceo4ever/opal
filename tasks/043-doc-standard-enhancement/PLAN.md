### 2. IA 유형 특이사항 명시

IA 행에 다음 내용을 비고 또는 별도 노트로 추가:
- md는 구조 개요 정리용, 실질 내용(메뉴 구조 + 기능 정의)은 JSON으로 작성 추천
- 상세 JSON 스키마는 opwt의 `references/network-guide.md` 참조

### 3. 섹션 10 "출력 형식 규칙" 신규 추가

기존 섹션 9(작업 보고 규칙) 뒤에 추가:

- 기본 출력: `.md` (Markdown)
- `.docx` 변환 시: 이미지는 상대 경로 대신 인라인 삽입, 복잡한 마크다운 테이블은 단순화
- `.pdf` 변환 시: 페이지 나눔 고려, TOC 포함 권장
- `.xlsx` 변환 시: JSON 데이터의 시트 매핑 규칙 명시 (IA 등)

### 4. 변경이력 갱신

v2.0 (Major) — 문서 유형 6종 추가 + 출력 형식 섹션 신규
