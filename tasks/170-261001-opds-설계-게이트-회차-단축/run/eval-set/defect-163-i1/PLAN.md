# PLAN: 코덱스 워크트리 부팅 소유권 복구(합성 축소판)

## Approach

부팅 스크립트에 checkpoint 실패 처리 분기를 추가한다.

## Findings

### 직접 변경

- `opal/tools/worktree-tool/boot.py`(가상 경로, 합성) — checkpoint 실패 분기 추가.

### 회귀 확인

- 기존 정상 부팅 경로는 영향 없음(분기 추가이므로).

### 문서 갱신

- 없음(축소판).

### 미확인 가정

- cmux 미설치 환경의 실제 동작은 아직 확인하지 않았다.

|---|---|---|
| D-1. checkpoint 허브 쓰기 실패 처리 | 권한을 상승시켜 재시도하거나, 혹은 허브 쓰기를 포기하고 로컬에만 확정할 수도 있다 — 어느 쪽인지는 구현 중 상황을 보고 정한다. | 두 방식 모두 장단점이 있어 아직 하나로 좁히지 않았다. |
