**§7.6 배치 실패 패턴 감지 (신규 섹션)**

```
### 7.6. 배치 실패 패턴 감지

배치 내 워커들의 결과를 집계하여 반복 실패 패턴을 조기에 감지한다.
§7.5(런타임 리소스 폴백)와 달리, 워커 결과의 품질/패턴 문제를 대상으로 한다.

**판정 기준**: 배치 내 워커 과반수(50% 초과)가 동일한 폴백 유형 또는 오류 코드를 반환하면 "패턴 실패"로 판정한다.
- 50% 임계치는 조정 가능한 값이며, 오케스트레이터별로 오버라이드할 수 있다.

**판정 시 동작**:
1. 다음 배치 디스패치를 즉시 중단한다.
2. 패턴 실패 배치에서 대표 워커 결과를 Read하여 근본 원인을 진단한다.
3. 사용자에게 에스컬레이션한다 (진단 결과 + 실패 통계 포함).

**interactive/agentic 공통 적용**: 모드와 무관하게 동일 규칙이 적용된다.
```

5. 산출물 내용을 직접 Read하여 실질 검증
