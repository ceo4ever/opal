# TASK: 프로젝트별 포트 매니저 CLI 도구 (r2-port)

> 작성일: 2026-03-09 | 작업 유형: 신규 개발

## 작업 목표

다중 프로젝트 환경에서 포트 충돌 없이 프론트엔드/백엔드 서버를 관리할 수 있는 CLI 도구(`r2-port`)를 개발한다.

## 배경

여러 AI 프로젝트를 동시에 개발하면서 프론트엔드(3000), 백엔드(8080) 등 기본 포트가 충돌하는 문제가 반복 발생한다. 각 프로젝트에 고유한 로컬 도메인과 포트를 자동 할당하고 중앙에서 관리하면 이 문제를 근본적으로 해결할 수 있다.

## 요구사항

- [ ] 프로젝트별 로컬 도메인(`{project}.front.local`, `{project}.api.local`)을 자동 생성하고 빈 포트를 할당
- [ ] 이미 등록된 도메인은 기존 포트를 반환 (재사용)
- [ ] 중앙 레지스트리(`~/ports.json`)에서 맥북별로 독립 관리
- [ ] `/etc/hosts`에 도메인 → `127.0.0.1` 자동 등록 (R2 마커 방식)
- [ ] 프레임워크별(Next.js, FastAPI 등) 실행 스크립트에 내장 가능한 출력 지원
- [ ] AI 스킬(port-mgr)로 프로젝트 셋업 시 자동 호출
- [ ] 수동 CLI로도 등록/해제 가능
- [ ] `install-mac.sh`에 설치 메뉴 추가

## 제약 조건

- macOS 전용 (Linux 확장은 추후 고려)
- `/etc/hosts` 수정 시 `sudo` 필요 — 거부 시 graceful 처리
- 외부 의존성 최소화 (python3은 macOS 기본 포함이므로 JSON 파싱에 활용 가능)
- 포트 범위: 프론트(3000~3999), API(8000~8999), 기타(9000~9999)

## 관련 문서

- `scripts/install-mac.sh` — 기존 설치 스크립트
