## 작업 목표

AGENT.md 부트스트랩 전체 시퀀스의 강제성을 높여, 어떤 단계도 건너뛸 수 없도록 만든다.
특히 `opal-harness.md` 미로드가 구현 금지 원칙·게이트 프로세스 무효화로 이어지는 경로를 차단하고,
부트스트랩 완료 여부를 세션 초기에 캡틴이 외부에서 즉시 확인 가능하게 한다.

## 배경

### 발생 경위

059 작업에서 알투가 PLAN 단계를 건너뛰고 바로 파일을 수정했다.

### 원인 추적

```
부트스트랩 4단계 skip (opal-harness.md 미로드)
  → §1 구현 금지 원칙 미인지
    → "이어서 작업해줘" = 즉시 실행 허가로 오해
      → PLAN → 승인 → EXECUTE 게이트 무시
```

### 현재 AGENT.md 구조의 취약점

- 부트스트랩 1~9단계가 모두 동등하게 나열되어 있어, 단계를 건너뛰어도 즉시 탐지되지 않음
- `opal-harness.md`가 "참조 문서" 그룹(step 4)에 묶여 있어 다른 참조 파일과 동일한 우선순위로 처리됨
- 부트스트랩 섹션에 "건너뛰면 안 된다"는 강제성 언어가 없어 생략을 막는 명시적 장치가 없음
- 부트스트랩 완료 후 캡틴에게 보고하는 의무가 없어 누락 여부를 외부에서 확인 불가
