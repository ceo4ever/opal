# archive — oppl 수행분 (2026-09-12 ~ 09-13)

이 폴더는 태스크 123을 **oppl(2-루프 수렴)로 수행한 기록**이다. 2026-09-14에
파일럿을 **opd**로 전환하면서 캡슐을 교체했고, 그 이전 산출물을 여기 보존한다.

## 왜 전환했나

oppl은 백로그 태스크마다 전체 파이프라인(T1 설계 · T2 RED · G 심판 · T3 구현 ·
T4a 테스트 · T4b 규칙검사 · T5 마무리)을 반복 실행한다. 태스크 123은 Phase 0~1C,
공용 코어, 상태 도구, 파이프라인 10종, 어댑터, 대시보드, 하네스를 한 태스크에
넣어 백로그가 16건이 됐고, 그 결과 단계 실행이 35회로 불어났다.

11시간 17분 경과 시점에 백로그 5/16, AC 8/20. 캡틴 판단으로 파일럿을 opd로 바꾸고
범위를 "기록 기반 완성"으로 좁혔다. **oppl 자체의 결함이 아니라 범위 단위를 잘못
잡은 것이 원인이다** — oppl이 전제하는 "얇은 수직 슬라이스"와 맞지 않았다.
