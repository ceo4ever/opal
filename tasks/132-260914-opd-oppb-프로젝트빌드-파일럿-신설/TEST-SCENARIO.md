> 입력: [TASK.md](TASK.md), [PLAN.md](PLAN.md) | 작성자: PM
> RED-first 트랙: **부분 적용**. `opal-agent`·`state-tool` 확장과 `oppb-runtime-tool` 전 모듈은 공개 동작을 테스트로 먼저 고정할 수 있고 회귀 위험이 크므로 `구현 전 RED`다. 스킬·에이전트·레지스트리·문서 동기화는 행위 불변 문서 작업이므로 결정론 검사와 실제 적용 확인으로 `구현 후` 검증한다. fixture 18회 실행은 배포 자산으로 수행하므로 `설치 후`다. 판정 근거: `harness/red-first.md` §1.

## Setup

- 환경: macOS, Python 3 표준 라이브러리 전용(`opal/tools/*` 관례), `git` 2.x. 워크트리 `.opal-worktrees/task_132`, 허브 `/Volumes/Data/AIStudio/workspace/ai-framework`.
- 공통 데이터: 실제 git 저장소 fixture(임시 디렉토리에 `git init`으로 생성). `opal-agent` 회귀용 golden 산출물 4종(`.result.json`·`.events.jsonl`·`.err.log`·`.exitcode`)은 변경 **전** HEAD에서 먼저 수집해 보관한다.
- 대역 사용과 한계: **사용하지 않음.** PLAN이 W-2·W-10·W-17·W-28·W-35 전 스위트에 mock 금지를 명시했다. 프로세스·파일시스템·git은 실물만 사용한다. 유일한 예외는 S-16의 결함 주입으로, 이는 대역이 아니라 의도적 오류 상태 구성이다.
- 실행 조건: S-1~S-18은 자동 실행. S-19·S-20은 배포(`scripts/install-mac.sh`) 후 실행. S-19는 실행 전 소유자에게 예상 시간·모델 비용을 보고하고 승인을 받아야 시작한다(사용자 협업 조건).
