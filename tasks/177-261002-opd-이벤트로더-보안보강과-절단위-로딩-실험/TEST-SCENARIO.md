# TEST-SCENARIO: 이벤트 로더 보안 보강(GC-004·006·011·012) + 절 단위 로딩(P3) 실험

> 입력: [TASK.md](TASK.md), [PLAN.md](PLAN.md) | 작성자: PM

## Setup

- 환경: macOS, 이 워크트리(`feat/OP-TASK-177`), `~/.opal/.venv/bin/python3`(`pytest`), `node`. 결정론 시나리오는 소스 실행(`opal/tools/event-loader/event_loader.py`)과 임시 폴더·임시 프로젝트 루트·임시 원장만 쓰고 `~/.opal`과 이 태스크의 `state.json`을 수정하지 않는다. 원장은 `OPAL_EVENT_LOADER_TEST_MODE=1`과 `OPAL_EVENT_LOADER_LEDGER`로 임시 파일을 가리킨다(테스트 모드를 끄는 시나리오는 서브프로세스 환경에서 명시적으로 제거한다).
- 공통 데이터: 매니페스트·문서·선언은 이 저장소의 실제 `opal/core/references/events.json`·`opal/core/references/harness/*.md`·`opal/core/references/opal-pm.md`·`opal/core/references/sections/*.json`이다. 심볼릭 링크·FIFO·사본 매니페스트는 임시 폴더에 만든다. 끈 호출의 기준값은 이 태스크 시작 커밋(`e501bdb0`)의 loader를 임시 체크아웃(`--source-root`)에서 실행한 출력이다.
- 대역 사용과 한계: 사용하지 않는다. event-loader·state-tool·정적 검사는 모두 실제 코드를 실행한다. 프로브(측정 작업)만 `opal-agent` 헤드리스 실호출이며 시나리오가 아니라 W-6 측정 작업이다.
- 실행 조건: 자동 실행(사람 협업 없음). S-12·S-13의 설치본 부분은 EXECUTE 뒤 `scripts/install-mac.sh` 배포가 끝난 설치본에서만 실행하며 설치가 불가능하면 `blocked`로 반환한다.
- 병렬 그룹: S-1, S-2, S-3, S-4, S-5, S-8 — 서로 선행 관계가 없고 각자 임시 폴더·임시 원장만 쓰며 공유 자원을 쓰지 않는다. 나머지는 순차 실행한다.
