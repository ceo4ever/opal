### 3.2 미시 설계 — greeting.md 구성 개요

> 근거: `CONTRACT.md:8` (형식: H1 1개 + 본문 2줄 이상), MV-2 패턴 `^# `

- **H1 제목 (1개)**: `# Greeting` — 줄 시작에 `# `(샵 + 공백) 포함. MV-2의 `grep -c '^# '`가 최소 1을 반환하도록 정확히 이 포맷 사용. `[MUST]` H1은 정확히 1개만 두어 계약 "H1 제목 1개"를 준수한다.
- **본문 (2줄 이상)**: 인사 문구 2줄 이상. 예:
  - 1줄: 이 문서가 opal-agent 채널 완주 실증용 최소 슬라이스임을 안내하는 문장
  - 2줄: greeting 슬라이스가 정상 생성되었음을 나타내는 문장
- **파일 위치**: `out/` 하위. 상위 `out/` 디렉토리가 없으면 T3 구현 시 먼저 생성한다(H-1 대응).

예시 본문(참고용, T3에서 확정):

```markdown
# Greeting

opal-agent 채널 완주 실증용 최소 greeting 슬라이스입니다.
이 문서가 정상 생성되면 T01 정상 슬라이스 경로가 검증됩니다.
```
