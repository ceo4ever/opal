## 3. 발견 사항

### High (4건)

**GC-001** [`scripts/install.sh:217-229`, `scripts/install/windows.ps1:181-200`, `opal/tools/opal-cli/lib/update.sh:163-183`] sha256sums.txt 부재 시 체크섬 검증 무조건 skip
- 카테고리: OWASP-A08 (Software and Data Integrity Failures)
- 영향: main 브랜치/release 자산 결손/MITM/repo 조작 어떤 경로에서든 사용자가 인지 못한 채 임의 tarball 실행
- 해결: release tag(v*) 패턴이면서 sha256sums.txt 다운로드 실패 시 사용자 동의 prompt 또는 `--insecure` 명시 플래그 요구. main 브랜치는 stdout에 "UNVERIFIED" 경고. 비대화형 모드(pipe, OPAL_AUTO_INSTALL=1)에서는 기본 거부.

**GC-002** [`opal/skills/opal-skill-manager/SKILL.md:60-72, 129-143`] third-party 스킬 fetch에 commit_sha 핀·실행 파일 검증·라이선스 Unknown 강조 누락
- 카테고리: OWASP-A08 + CWE-829 (Inclusion of Functionality from Untrusted Source)
- 영향: 142가 도입한 `npx skills add` / `git clone` 흐름에서 supply-chain 위험. 동의 prompt가 라이선스 표시뿐 — `license: "Unknown"` 12개 항목 강조 없음, latest HEAD 변경 감지 불가, 다운로드 후 임의 실행 파일 sandboxing 없음
- 해결: registry에 `commit_sha` 필드 추가 + 다운로드 후 SHA 검증 / `license: "Unknown"` 항목 빨간 경고 + 두 번째 확인 강제 / fetch 후 실행 가능 파일 두 번째 동의 / `~/.opal/community-skills/SECURITY.md` 또는 부트스트래퍼에 신뢰 모델 명시

**GC-003** [`scripts/install-mac.sh:1041-1046`, `opal/tools/opal-cli/lib/mcp.sh:155-198`, `scripts/install/windows.ps1:1086-1107`] MCP `command`/`args`가 JSON 파일에서 그대로 spawn — fork된 repo 임의 명령 영구 등록 가능
- 카테고리: CWE-78 (OS Command Injection) + OWASP-A08
- 영향: `OPAL_REPO=attacker/opal`로 install 시 임의 command 등록 → `~/.claude.json`/`~/.cursor/mcp.json`에 영속 백도어
- 해결: `opal/core/mcps/*.json` `command` 화이트리스트(`npx`, `npm`, `node`, `python3`만) / args 첫 토큰 패턴 검증 / `OPAL_REPO != ceo4ever/opal`인 경우 banner 경고 + 사용자 명시 동의 / release tag 무결성 통과 시에만 비대화형 자동 등록

**GC-004** [`opal/tools/skill-registry/skill-registry.js:101-122, 305-316`] community trigger 정규식이 사용자 통제 입력에 대해 컴파일·실행되며 ReDoS 방어 없음
- 카테고리: CWE-1333 (Inefficient Regular Expression Complexity) + CWE-20
- 영향: catastrophic backtracking 시 Node.js 이벤트 루프 영구 정지. `(?i)(stitch.*react|react\s*component.*stitch)` 같은 `.*A.*B` 패턴 위험
- 해결: 패턴 길이 100자 초과/`.*` 2회 이상/nested quantifier 검출 시 reject / Node.js v17+ AbortController로 timeout 100ms 강제 / 입력 길이 제한 256자 / 또는 `re2-wasm`으로 교체

### Medium (6건)

**GC-005** [`opal/tools/requirements.txt`] Python 의존성 모두 `>=` lower-bound만 — 정확한 핀 없음
- 카테고리: OWASP-A06 (Vulnerable and Outdated Components)
- 해결: `pip-compile`로 `requirements.lock` 생성·커밋, install이 lock 우선 사용. 호환 보수성 위해 `>=x.y,<X+1.0` 상한이라도 추가

**GC-006** [`opal/core/mcps/playwright.json`, `sequential-thinking.json`, `context7.json`, `shadcn.json`] MCP 서버 의존성 모두 `@latest` 또는 버전 미고정
- 카테고리: OWASP-A06 + A08
- 해결: `@latest` 제거 + 마이너 버전 핀 / 신규 MCP 추가 시 `version_pinned: "x.y.z"` 의무화

**GC-007** [`opal/core/mcps/playwright.json:6`] `--output-dir /tmp/playwright-mcp` — 다중 사용자 시스템 race + symlink 위험
- 카테고리: CWE-377 (Insecure Temporary File) + CWE-22 (Path Traversal)
- 해결: 경로를 `~/.opal/cache/playwright-mcp/` (0700) 또는 `mktemp -d`로 매 세션 생성. (Windows는 install.ps1 `$env:TEMP\playwright-mcp`로 이미 치환됨, mac/Linux만 영향)

**GC-008** [`scripts/install-mac.sh:127-153, 363-400`] hooks/MCP JSON schema 미검증 — fork된 `claude-hooks.json` / `mcps/*.json`이 임의 키로 영속화
- 카테고리: CWE-94 (Code Injection 매개)
- 해결: `claude-hooks.json` / `mcps/*.json` JSON Schema 검증 단계 추가. 알려지지 않은 키나 비표준 필드 reject

**GC-009** [`scripts/install/macos.sh:38-40`, `install-mac.sh:660-672, 798-820`] 자동 `chmod +x` — install 시 임의의 `run.sh`에 실행 권한 부여
- 카테고리: CWE-269 (Improper Privilege Management) + CWE-276
- 해결: `chmod 0755` 명시 / 0700 사용자 한정 / install 전에 파일이 `~/.opal/` 하위인지 `realpath` 검증

**GC-010** [`opal/tools/opal-cli/lib/uninstall.sh:67`, `install-mac.sh:736`, `install/windows.ps1:418`] `rm -rf "$opal_home"` — `OPAL_HOME=/`로 설정 시 시스템 손상 가능
- 카테고리: CWE-22 (Path Traversal) + CWE-732
- 해결: `[[ "$opal_home" == "$HOME/.opal" ]] || error` 가드 추가 / 절대 경로 + `realpath` 결과가 `$HOME` 하위인지 확인
