## 1. 태스크 개요 + 기능 리스트업

### 1.1 요약

oppd(`opal-pilot-project-dev`) 파이프라인을 3개 축으로 개선한다: ① PRD/TRD를 태스크 폴더에서 작성 후 확정분만 docs/로 승격하는 프로세스(#1), ② WBS 액션 세분화를 "단일 책임 + 단일 수용 시나리오로 독립 검증 가능한 단위"로 재정의(BE/FE 분할 기준 포함, #2), ③ 액션 실행을 선형 6단계에서 실패 분류(triage) 기반 경계 재설계 루프(B7)로 전환. 변경 대상은 전부 프레임워크 소스 `.md` 문서 7개이며, 배포본(`~/.opal/`) 직접 편집은 금지된다.
