### 1.2 홉 정의 (재현 가능한 규칙)

| 홉 | 정의 |
|----|------|
| 1홉 | pilot SKILL.md(또는 그에 준하는 진입 스킬)가 **직접** Read 지시 |
| 2홉 | 1홉 문서가 Read 지시 |
| 3홉 | 2홉 문서가 Read 지시 |
| 4홉+ | 이하 동일 — **본 문서는 4홉에서 절단**한다(하위 확장 없음) |

각 문서는 **그래프상 최단 경로**로 홉을 계상한다(동일 문서가 여러 경로로 도달 가능하면 가장 짧은 경로를 채택). 간선마다 근거 줄번호를 §3·§5에 기재한다.

### 1.3 홉 추적 절차

`grep -n -E 'Read|references/|harness/|\.md'` 로 각 문서의 참조 지시를 추출한 뒤, 지시문이 **실제 Read 지시**(탐색 경로/역할 명시)인지 단순 인용(citation)인지 구분했다. 단순 인용(예: 변경이력의 역사적 서술, 수치 SSOT 포인터 각주)은 간선으로 계상하지 않았다 — 로드 지시가 아니기 때문이다.
