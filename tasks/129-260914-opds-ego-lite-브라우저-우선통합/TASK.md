# TASK: Ego Lite 브라우저 우선 통합

## Problem
OPAL의 브라우저 작업과 E2E 실행 경로는 선언된 공급자 우선순위와 실제 어댑터 동작이 일치하지 않고, Ego Lite가 설치되지 않은 환경에서 설치 선택과 원래 작업 재개를 연결하는 흐름도 없다. 이 때문에 인증·동적 화면·사용자 상호작용을 포함한 브라우저 검증을 일관된 1급 경로로 수행할 수 없다.

## Proposed outcome
Ego Lite를 브라우저 상호작용과 E2E의 우선 공급자로 사용할 수 있고, 사용할 수 없을 때는 사용자가 직접 설치하거나 R2가 안전하게 설치하거나 취소하는 선택을 한 뒤 원래 작업을 이어간다. 공개 정보 검색은 기존 웹 검색을 유지하며, Ego Lite에 적합한 작업만 명확한 대체 규칙에 따라 실행된다.

## Affected users and systems
영향 대상은 OPAL을 사용하는 캡틴과 PM·테스트 에이전트, 브라우저 작업을 라우팅하는 테스트 도구·웹 변환 스킬·도구 탐지·설치 및 진단 경로다. macOS의 Ego Lite 설치·온보딩과 커뮤니티 스킬 등록을 포함한다. Ego Lite 애플리케이션의 재배포, Windows/Linux용 미지원 기능 구현, 공개 웹 검색 엔진 교체는 범위에서 제외한다.

## Constraints
- C-1: 공개 정보 검색은 기존 웹 검색을 사용하고, 인증 세션·동적 페이지·UI 상호작용·E2E만 Ego Lite 우선 대상으로 삼는다.
- C-2: Ego Lite 미설치 시 사용자에게 직접 설치, R2 설치, 취소 중 하나를 묻고 설치·온보딩 확인 뒤 중단된 원래 작업을 재개한다.
- C-3: 공급자 대체는 `provider_unavailable`일 때만 허용하며 테스트 실패·인프라 오류·차단 상태를 다른 공급자로 숨기지 않는다.
- C-4: macOS 외 환경과 설치 불가 환경은 기능 부재로 판정해 기존 공급자로 안전하게 대체한다.
- C-5: 외부 스킬의 출처·라이선스·고정 커밋을 기록하고, 다운로드 산출물은 무결성·코드서명·공증을 검증한 뒤에만 설치한다.
- C-6: 비밀번호·쿠키·토큰을 내보내지 않고, 인증·결제·게시 등 외부 부작용 행동은 기존 사용자 승인 경계를 유지한다.
- C-7: `~/.opal/` 배포본을 직접 수정하지 않고 프로젝트 소스를 수정한 뒤 설치 절차로 배포 정합성을 검증한다.

## Acceptance criteria
- AC-1: 브라우저 상호작용과 E2E의 공급자 순서가 Ego Lite → cmux → Playwright로 선언과 실행에서 일치한다.
- AC-2: 공개 웹 검색 요청은 Ego Lite 공급자 선택과 무관하게 기존 웹 검색 경로를 사용한다.
- AC-3: Ego Lite 미설치 판정이 직접 설치·R2 설치·취소의 구조화된 사용자 선택을 반환하고, 설치 완료 뒤 원래 요청 재개에 필요한 컨텍스트를 보존한다.
- AC-4: R2 설치 경로는 지원 운영체제와 아키텍처를 확인하고 DMG 무결성·서명·공증 검증을 통과한 경우에만 설치하며, GUI 온보딩이 필요하면 `awaiting_human`으로 전환한다.
- AC-5: Ego Lite 실행 결과가 OPAL E2E 계약의 `pass`, `fail`, `executor_unavailable`, `infra_error`, `blocked`, `awaiting_human`으로 결정론적으로 정규화된다.
- AC-6: Ego Lite가 없거나 지원되지 않는 환경에서는 `provider_unavailable`에 한해 cmux, 이어서 Playwright로 대체되고 그 밖의 상태에서는 대체가 중단된다.
- AC-7: 공식 `ego-browser` 스킬이 출처·MIT 라이선스·고정 커밋 정보와 함께 OPAL 커뮤니티 스킬로 설치·조회 가능하고, 현재 Codex 환경에도 설치되어 다음 세션부터 사용할 수 있다.
- AC-8: 웹 변환 스킬·테스트 에이전트·도구 문서·진단/탐지 경로가 같은 라우팅과 설치 안내를 사용한다.
- AC-9: 자동 테스트가 공급자 선택, 미설치 핸드오프, 상태 정규화, 대체 차단, 비지원 플랫폼을 검증하고, 설치·온보딩된 Ego Lite로 무해한 실제 브라우저 E2E 1건을 증거로 남긴다.
- AC-10: 기존 cmux·Playwright 경로와 공개 웹 검색 경로의 회귀 테스트가 통과한다.
