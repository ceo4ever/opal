## 제약 조건

- **단일 파일 수정**: `README.md`만 변경한다. 다른 문서(CLAUDE.md, docs/*, scripts/*)는 수정하지 않는다.
- **소스 vs 배포 경계**: `~/.opal/` 경로의 파일을 Edit/Write하지 않는다 (확정 기준 #2).
- **커밋 금지**: EXECUTE 완료 후에도 자동 커밋하지 않는다 (하네스 §1 커밋 규칙). 캡틴의 명시적 지시가 있을 때만 커밋한다.
- **경로 정확성**: R-8에서 언급하는 설치 경로는 `scripts/install-mac.sh`의 실제 구현을 Read로 확인 후 반영한다 (추측 금지).
- **agentic 모드 의무**: 매 게이트에서 판단 근거를 `AGENTIC-LOG.md`에 기록한다. 산출물은 체크리스트가 아닌 내용 수준까지 직접 Read 검증.
