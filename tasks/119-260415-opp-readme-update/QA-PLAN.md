## 3. 지적 사항

### Warning 1: community-skills 숫자 불일치 (Info)

- **심각도**: Info
- **내용**: PLAN §2 Step 10에서 "커뮤니티 스킬 수 31개 → 37개로 정정"이라고 기재했으나, 소스 리포지토리의 `community-skills/` 디렉토리에는 6개 조직 폴더 아래 31개 스킬이 존재한다. 37개의 근거가 불분명하다. 배포된 `~/.opal/community-skills/`에는 49개가 있어 소스와 배포 간 차이도 있다.
- **권장 조치**: EXECUTE 시 소스 기준 31개를 유지하거나, 정확한 수를 재확인하여 반영한다. PLAN §5에서도 "동적 숫자 대신 근사치 사용 고려"를 언급하고 있으므로 리스크는 인지되어 있다.

### Warning 2: 설치 섹션 줄 범위 미미한 차이 (Info)

- **심각도**: Info
- **내용**: PLAN은 설치 섹션을 "60~77줄(18줄)"로 기재했으나, 실제로는 60~76줄(17줄). 마지막 내용줄은 76("설치 후 AI 도구를 재시작하면...")이고 77줄은 빈 줄이다. TASK.md도 "17줄"로 기재하고 있어 PLAN과 TASK 사이에 미미한 불일치가 있다.
- **권장 조치**: EXECUTE에 영향 없는 수준이므로 수정 불요.
