# TEST-SCENARIO: stockctl 다중 위치 재고·이동·감사·가져오기·충돌 감지

> 입력: [TASK.md](TASK.md), [PLAN.md](PLAN.md) | 작성자: PM

## Setup

- 환경: 워크트리 루트에서 Python 3 + pytest. CLI는 `subprocess.run([sys.executable, "-m", "stockctl", "--store", <tmp_path>/s.json, ...], capture_output=True, text=True)`로 호출한다(`tests/test_basic.py`와 같은 방식). 시나리오마다 pytest `tmp_path`로 독립 저장소를 쓴다.
- 공통 데이터: 저장소 `S = tmp_path/"s.json"`, 감사 파일 `S.audit.jsonl` = `tmp_path/"s.json.audit.jsonl"`. "바이트 불변"은 실패 명령 전후 `S.read_bytes()`가 같음, "감사 불변"은 감사 파일이 없던 상태면 계속 없고 있던 상태면 내용이 같음을 뜻한다.
- 대역 사용과 한계: 사용하지 않음. 실제 CLI 프로세스와 실제 파일로 검증한다.
- 실행 조건: 자동 실행. 신규 테스트 파일은 `tests/test_multiloc.py`.
- 병렬 그룹: 선언 없음(순차).
