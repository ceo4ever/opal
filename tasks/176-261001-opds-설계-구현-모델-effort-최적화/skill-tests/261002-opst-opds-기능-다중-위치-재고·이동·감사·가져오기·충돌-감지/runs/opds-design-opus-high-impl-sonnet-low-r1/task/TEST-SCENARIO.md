## Setup

- 환경: worktree `.opal-worktrees/task_001`, Python 3.14 + pytest 9(실측 `python3 -m pytest --version`). CLI는 `python -m stockctl --store <tmp_path>/s.json ...`을 subprocess로 호출한다(`tests/test_basic.py:14-16` 방식). 각 시나리오는 pytest `tmp_path`로 독립 저장소를 쓴다.
- 공통 데이터: 구형 형식 저장소는 테스트가 직접 JSON을 쓴다 — `{"items": {"A1": {"name": "Apple", "qty": 5, "location": "MAIN"}, "B2": {"name": "Box", "qty": 0, "location": "WH2"}}}`(version 키 없음). "바이트 불변"은 명령 전후 `Path.read_bytes()` 동일 비교, "감사 무기록"은 `<저장소>.audit.jsonl`의 줄 수(부재 = 0) 전후 동일 비교로 판정한다.
- 대역 사용과 한계: 사용하지 않음(실제 CLI 프로세스·실제 파일).
- 실행 조건: 자동 실행. 사람 협업 없음.
- 병렬 그룹: S-1, S-2, S-3, S-4, S-5, S-6, S-7, S-8, S-9, S-10, S-11, S-12
