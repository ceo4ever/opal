# TEST-SCENARIO: stockctl 다중 위치 재고·이동·감사·가져오기·충돌 감지

> 입력: [TASK.md](TASK.md), [PLAN.md](PLAN.md) | 작성자: PM

## Setup

- 환경: 워크트리 루트(`.opal-worktrees/task_001`)를 cwd로 한 로컬 Python 3 + pytest. CLI는 `python -m stockctl --store <tmp_path>/s.json ...` subprocess로 호출한다(`docs/CONVENTIONS.md`).
- 공통 데이터: 각 테스트는 pytest `tmp_path` 아래 새 저장소 `s.json`을 쓴다. 감사 로그는 `s.json.audit.jsonl`, 가져오기 CSV는 `tmp_path/in.csv`, 거부 파일은 `tmp_path/in.csv.rejected.csv`. "바이트 불변"은 명령 전후 `Path.read_bytes()` 비교, "감사 무기록"은 명령 전후 감사 파일 줄 수(부재 시 0) 비교로 판정한다.
- 레거시 픽스처: `{"items": {"A1": {"name": "Apple", "qty": 5, "location": "W1"}, "B2": {"name": "Banana", "qty": 0, "location": "MAIN"}}}` (`version` 없음)을 테스트가 직접 기록한다.
- 대역 사용과 한계: 사용하지 않음 — 실제 CLI 프로세스와 실제 파일을 사용한다.
- 실행 조건: 자동 실행. RED 테스트 파일 `tests/test_multiloc.py`의 함수명은 `test_s01_...`~`test_s12_...`로 S-ID와 1:1 대응한다.
- 병렬 그룹: 선언 없음(순차).
