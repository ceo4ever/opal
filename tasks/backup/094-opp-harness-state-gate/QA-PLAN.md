## 1. 요약

이 PLAN은 하네스 State Gate 관련 수정 사항 대부분이 이전 세션에서 이미 완료되었음을 현황 조사로 확인하고, 유일한 미완성 항목인 `op-task/SKILL.md` "배경 분석" 섹션 추가만을 구현 범위로 정의한다. 수정 대상은 1개 파일이며, 변경 위치 3곳(대화 내용 반영 절차, TASK.md 템플릿, 작성 체크리스트)에 대해 Before/After 코드 블록을 포함한 구체적인 설계가 제공된다. 의존관계 없는 단일 Step으로 구성되어 즉시 실행 가능하다.
