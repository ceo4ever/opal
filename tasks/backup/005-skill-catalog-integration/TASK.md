# Awesome Agent Skills 카탈로그 통합

> 작성일: 2026-03-09 | 작성자: OPAL | 버전: v1.0

## 목적

[ceo4ever/awesome-agent-skills](https://github.com/ceo4ever/awesome-agent-skills) 리포지토리의 549개+ 외부 스킬을 OPAL 에이전트 프레임워크에 통합하여, AI가 필요한 스킬을 검색하고 설치할 수 있도록 한다.

## 배경

- OPAL 에이전트는 현재 자체 스킬(task-flow, api-analyzer, doc-writer 등) 6개와 OPAL 전용 스킬 3개를 보유
- 외부 커뮤니티와 공식 팀들이 만든 549개+ 스킬이 있으나, 수동으로 찾아 설치해야 함
- 사용자가 프로젝트에 필요한 스킬을 AI에게 요청하면 자동으로 검색 → 설치가 가능해야 함

## 요구사항

### R1: 스킬 카탈로그

- ceo4ever/awesome-agent-skills README.md를 파싱하여 스킬 카탈로그(색인)를 구성
- 카탈로그는 스킬명, 설명, 소스 URL, 카테고리를 포함
- AI가 사용자 요청에 맞는 스킬을 카탈로그에서 검색 가능

### R2: 기본 번들 (auto-install)

- 범용적으로 유용한 스킬을 기본 번들로 선정
- install-mac.sh의 OPAL 설치 시 기본 번들을 함께 설치
- 기본 번들은 개발, 문서, 보안 등 핵심 카테고리에서 선별

### R3: 온디맨드 검색 및 설치

- AI가 카탈로그를 검색하여 관련 스킬을 추천
- 사용자 승인 후 git clone으로 스킬을 설치
- 설치된 스킬은 각 플랫폼의 skills 디렉토리에 배치

### R4: 스킬 관리

- 설치된 외부 스킬 목록 조회
- 스킬 삭제/업데이트 지원

## 범위

### In Scope

- 스킬 카탈로그 파일 생성 (Markdown 기반)
- OPAL skill-manager 스킬 작성 (검색/설치/관리)
- install-mac.sh에 기본 번들 설치 로직 추가
- 기본 번들 스킬 선정

### Out of Scope

- MCP 서버 통합 (별도 태스크로 분리)
- 스킬 보안 감사 자동화
- 웹 기반 스킬 마켓플레이스 UI
