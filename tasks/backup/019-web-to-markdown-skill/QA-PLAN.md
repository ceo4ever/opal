> 검토일: 2026-03-20 | 판정: ⚠️ Needs Revision

## 1. 요약

web-to-markdown SKILL.md의 기본/clean 모드 전환을 핵심 변경으로 다룬다. 현재 초안은 기본 모드에서 nav/header/footer/sidebar를 제거하도록 되어 있으나, TASK.md는 기본 모드에서 전체 콘텐츠를 보존하도록 요구하므로 WebFetch prompt와 "제거 대상" 섹션을 모드별로 분기하는 계획이다. 추가로 wtm-worker 에이전트 3개 플랫폼 파일 생성, 에이전트 탐색 경로 명시, OPAL 레지스트리 등록을 수행한다. 5개 Step으로 실행 체크리스트가 구성되어 있으며, QA 체크리스트는 기능/회귀/품질 3개 카테고리를 포함한다.

## 3. 지적 사항

### 3-1. Phase 2 브라우저 경로에서의 모드 분기 누락

- **심각도**: 🟡 Warning
- **내용**: 변경 1에서 WebFetch prompt의 모드별 분기는 상세히 기술되어 있으나, Phase 2(Playwright MCP browser_snapshot 또는 Playwright 스크립트로 획득한 HTML)에 대한 모드별 정제 규칙 분기가 언급되지 않았다. "본문 추출 및 MD 정제" 섹션의 "제거 대상" 목록을 모드별로 분리한다는 언급은 있으나(변경 1의 "공통 + clean 모드 추가 제거로 분리"), Phase 2 흐름에서 이 분기가 어떻게 적용되는지 명시적으로 연결되어 있지 않다.
- **권장**: 변경 1에 "Phase 1/2 공통으로 적용되는 정제 규칙이므로 Phase 2에도 동일하게 모드 분기가 적용됨"을 한 줄 명시하거나, Phase 2 섹션 수정도 변경 항목에 포함할 것.

### 3-2. Playwright MCP 연동 검토 요구사항의 PLAN 반영 근거 부재

- **심각도**: 🟡 Warning
- **내용**: TASK.md에 "Playwright MCP 연동 검토: MCP 있으면 우선 사용, 없으면 스크립트 폴백"이 요구사항으로 있다. 현재 SKILL.md 초안(72-92줄)에 이미 Playwright MCP 우선 사용 -> 스크립트 폴백 구조가 구현되어 있으므로 추가 변경이 불필요할 수 있으나, PLAN에서 "이미 충족됨"이라는 판단 근거가 명시되지 않았다. 요구사항이 누락된 것인지, 이미 충족되어 생략한 것인지 판단할 수 없다.
- **권장**: Part A 코드 분석 또는 Part B 도입부에 "TASK.md의 Playwright MCP 연동 검토 요구사항은 현재 SKILL.md v1.0 초안(Phase 2 섹션)에서 이미 구현되어 있으므로 추가 변경 불필요"라는 한 줄을 추가할 것.

### 3-3. QA 체크리스트에 Phase 2 모드 분기 검증 항목 부재

- **심각도**: 🔵 Info
- **내용**: QA 체크리스트 기능 테스트에 WebFetch prompt 모드 분기 확인은 있으나, Phase 2(browser_snapshot/스크립트 HTML) 정제 시 모드 분기 확인 항목이 없다. 지적 사항 3-1이 해결되면 자연스럽게 추가될 것으로 예상된다.
