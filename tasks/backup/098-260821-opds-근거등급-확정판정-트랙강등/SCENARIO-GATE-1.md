## 3. gaps (재작성 지시)

### G-1 (①목표달성) — 목표 검증의 in-task 자동 경로를 최소 1건 확보하라

`S-1`·`S-3`·`S-30`을 L3에서 끌어내리라는 지시가 아니다(강등 라우터·경량화 체감은 수동이 타당하다). **추가**할 것:

- **신규 시나리오 (L2 자동, 실파일)**: 본 태스크 `TASK.md`를 입력으로 `verify --evidence-check`를 실행한다. 기대 결과 — exit 0 / `## 명확화 결과` 4행의 `의존 사실` 셀 인용이 등급 부여되고 `confirmed_ratio`가 산출되며, **인용이 실제 기재된 3행이 `citation_missing`으로 강등되지 않는다**. 이것은 목표 문장 2절("근거 없는 추정이 확정으로 통과하는 구멍 제거")을 합성 픽스처(`FX-NEW`, tmp_path)가 아니라 실 산출물에서 검증하는 유일한 경로다. S-7은 tmp_path 합성 입력이므로 이 축을 대신하지 않는다.
- 위 시나리오는 동시에 ⑥의 공백(아래 권고)을 메운다 — 본 태스크 `TASK.md`의 실제 인용 형식이 `` `citation-rules.md` §2 ``(디렉토리 없는 파일명 + §), `` `.opal/MEMORY.json` history 096 항목 ``(경로 + 산문), `` `state_tool.py:2225`(`_parse_clarification_table`) ``(경로:줄번호 + 괄호 주석)로 **혼재**한다. `_grade_citation`이 `경로:줄번호` 단일 토큰만 가정하면 이 3형식이 전부 `citation_path_not_found`로 오강등된다.
- **S-1의 면제 근거 문장을 정정하라**(`TEST-SCENARIO.md:12`, `:519`). "자동 검증 불가"가 아니라 "**R-6 실작동(후속 태스크의 ANALYSIS·PLAN 거동)만** 자동 검증 불가"로 범위를 좁혀 기재하라 — 현재 문장은 도구 집행 절(R-4)까지 면제 대상으로 읽힌다.

### G-2 (⑤채택·잔존) — R-7 구형 잔존, R-3 신형 채택 인스턴스를 각 1건 추가하라

- **R-7 구형 잔존0 (신규, L1 grep 부재 검사)**: `plan-guide.md`에서 설계 절 서술이 "핵심 로직 정의"에서 "결정 + 근거 + 변경되는 공개 계약"으로 **교체**됐음을 검사한다. 기대 결과 — 구 조항(`plan-guide.md:139` "핵심 로직을 정의한다" 계열 서술) 잔존 0건. 현행 S-10은 신형 문장 **존재**만 보므로 신·구 공존을 통과시킨다. `op-dev-analysis/SKILL.md`에도 동일 검사를 병기하라(R-7 AC(a) 대상 문서).
- **R-3 신형 채택 인스턴스 (신규, L1/L2)**: 본 태스크 `TASK.md`가 신 템플릿 규약을 **자기적용으로 충족**함을 검사한다. 기대 결과 — `## 확정된 설계 방향` 14항 전건에 `[결정]`/`[사실]` 태그 부여 + `의존 사실` 셀이 `-` 허용 조건(순수 `[결정]` 행)을 위반하지 않음. S-12(R-7 자기적용)와 동형이며, 문서 존재 검사(S-6)로는 대체되지 않는다.
- **S-13의 축 표기를 정정하라** — 내용(레거시 19건 무차단)은 "구형 잔존 허용"이므로 R-3의 채택 면 근거로 §4 매핑 표(`TEST-SCENARIO.md:560`)·정규화 페이로드의 `is_adoption_scenario`에 계상하지 말라. 채택 면은 위 신규 시나리오가 담당한다.
