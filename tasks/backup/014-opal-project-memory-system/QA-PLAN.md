## 1. 요약

프로젝트별 `.opal/MEMORY.md`(인덱스) + `memory/*.md`(개별 파일) 구조로 메모리 시스템을 설계한다. 부트스트랩 시 인덱스만 읽고 관련 파일만 선택적 로드하여 토큰 효율을 확보한다. AGENT.md의 "기억과 학습" 섹션에 저장소 경로/규칙을 추가하고, orchestrator에 Step 1 메모리 로드 + Step 6 메모리 갱신을 추가한다. project-init에 의존하지 않고 소유자 요청 시 독립 생성이 가능하며, 프로젝트 에이전트 개편은 별도 태스크로 분리하여 스코프를 명확히 제한했다.
