# QA: PLAN -- task-flow STATE.md 체크포인트 시스템 추가

> 검토일: 2026-03-15 | 판정: Pass

## 1. 요약

task-flow 태스크 폴더에 STATE.md 체크포인트 파일을 추가하여 LLM 컨텍스트 유실 시에도 정확한 지점에서 작업을 재개하는 기능을 설계한다. STATE.md 템플릿은 현재 단계/Step 진행률, 의사결정 로그, 미반영 사용자 지시, 블로커 정보를 포함한다. 갱신 주체를 오케스트레이터(단계 전환)와 워커(Step 진행)로 분리하고, 기존 "이어하기" 기능을 STATE.md 존재 시 고도화/미존재 시 폴백하는 이중 경로로 설계했다. 변경 대상은 SKILL.md, execute-guide.md, 3개 플랫폼 워커 에이전트, CLAUDE.md 총 6개 파일이다.
