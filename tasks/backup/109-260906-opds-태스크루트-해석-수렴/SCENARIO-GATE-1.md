## 4. 관찰 (감점 아님)

- **O-1 (경미한 과대 산정)** — `TS-042`의 `is_goal_scenario: true`. 실체는 R-6 AC 기전(코호트 전건 관측·중앙값 재현) 검증이며 목표 진술(「양쪽 0 failed」) 직접 검증은 아니다. 목표축이 TS-070으로 이미 성립하므로 축 등급에 영향 없음.
- **O-2 (경미한 과대 산정)** — `TS-061`의 `is_goal_scenario: true`. 「목표 달성」이 아니라 「목표 달성 판정의 진위」를 지키는 메타 방어다. 다만 070 사건의 실패 양식(검증했다는 착각)을 정면으로 막으므로 목표축 근거로 채택하는 것을 타당하다고 판정했다.
- **O-3 (PM 보강 2건 정당성 판정 — 요청 항목)** — **둘 다 정당하다. 장식이 아니다.**
  - `TS-060`: TS-010은 「구현이 1개씩」, TS-011은 「**오늘** 답이 같음」을 본다. **표가 사본으로 갈라지는 경로**는 어느 기존 TS도 막지 않으며, 사본이 생기면 TS-011은 계속 통과하면서 드리프트가 시작된다. 게다가 M1(기계 검증)로 두어 판정 가능성도 확보했다. 실 빈틈 폐색으로 인정.
  - `TS-061`: TS-026은 「문서에 적혔는가」만 본다. H-9의 위험은 **사람의 오해**이고 문서 존재는 오해 방지를 증명하지 못한다. 문자열 단언으로 판정 불가하므로 M3 배정이 옳고, 실패 시 처방(「문서가 아니라 **출력**을 고쳐야 한다」)까지 지정돼 있어 판정 결과가 행동으로 연결된다. 실 빈틈 폐색으로 인정.
- **O-4 (편집 지적사항)** — `TS-026`이 「### L3」 표제 아래 배치돼 있으나 항목 표의 `계층`은 **L2**, 실행 방식은 M1(문서 grep)이다. 표제·필드 불일치이며 채점에는 영향 없다.
- **O-5** — R-3 AC(a)의 대상을 「`cwd()`·`__file__` 파생 조립」으로 좁힌 PLAN §AC 해석 고정은 근거(인자 기반 6곳은 값이 이미 허브 절대경로)가 문서화돼 있고, 그 전제는 TS-040~TS-043의 실 HTTP 경로로 간접 반증 가능하다. 은닉된 목표 축소로 보지 않는다.
