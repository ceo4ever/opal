# 요구서: stockctl 재고 부족 품목 조회

창고 담당자가 곧 떨어질 품목을 한 번에 확인할 방법이 없다. 아래를 구현한다.

- `stockctl low-stock --below N` 명령을 추가한다. 수량이 N 미만인 품목을 SKU 오름차순으로 `SKU\tQTY` 한 줄씩 출력하고 exit 0으로 끝난다.
- 해당 품목이 없으면 아무것도 출력하지 않고 exit 0이다.
- N이 정수가 아니거나 0 이하이면 stderr에 `invalid:`로 시작하는 한 줄을 쓰고 exit 5로 끝난다.
- 저장소 파일은 읽기만 하고 바꾸지 않는다.
- 기존 명령과 기존 테스트는 그대로 동작해야 하고 `docs/CLI.md`에 명령을 추가한다.
