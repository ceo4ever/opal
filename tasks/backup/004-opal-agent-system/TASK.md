# OPAL AI 에이전트 시스템

> 작성일: 2026-03-09 | 작성자: R2 | 버전: v1.0

## 1. 작업 유형

신규 개발

## 2. 목표

현재 페르소나 수준의 R2를 **범용 AI 에이전트 프레임워크(OPAL)**로 진화시킨다. 누구나 자기만의 AI 파트너를 정의하고, 프로젝트 오케스트레이션까지 수행하는 에이전트 시스템을 구축한다.

**OPAL** = Open Protocol for Agentic Links
빛의 각도에 따라 다채롭게 색이 변하는 오팔 보석처럼, 어떤 환경에 연결하든 그에 맞춰 유연하게 형태를 바꾸는 열린 구조.

## 3. 배경

### 현재 상태

- 알투(R2)는 페르소나 정의 수준 (이름, 성격, 톤이 하드코딩)
- 3개 AI 플랫폼(Claude Code, Cursor, Antigravity)에 동일 내용을 플랫폼 포맷으로 복사
- 다른 사람이 자기만의 AI 파트너를 만들 수 없음
- 프로젝트 오케스트레이션 기능 없음

### 현재 파일

| 파일 | 용도 | 문제 |
|------|------|------|
| `templates/r2/000-r2-persona.mdc` | Cursor용 페르소나 | 알투 하드코딩 (114줄) |
| `templates/r2/claude-snippet.md` | Claude Code용 스니핏 | 알투 하드코딩 (132줄) |
| `templates/r2/gemini-snippet.md` | Antigravity용 스니핏 | 알투 하드코딩 (134줄) |

## 4. 요구사항

### 4.1 범용 AI 에이전트 프레임워크

- 사용자가 자기만의 AI 파트너를 정의할 수 있어야 함 (이름, 성격, 호칭 자유)
- 예시: 알투(R2), 메듀사(까칠하지만 똑부러짐), 자비스 등

### 4.2 모듈화된 파일 구조

- 정체성, 역할, 행동규칙, 스킬을 별도 md 파일로 분리
- 관련 정의, 스킬, 툴 등을 모두 md 파일로 관리

### 4.3 온보딩 인터뷰

- 처음 시작 시 에이전트 정의가 없으면 자동으로 온보딩 시작
- 이름, 별칭, 소유자 호칭, 성격/톤 등 기본 항목 수집
- 온보딩 중 추가 항목도 정의 가능 (확장 가능한 구조)
- identity.md 파일로 고정 저장

### 4.4 프로젝트 오케스트레이터

- 프로젝트 시작 시 프로젝트 에이전트 확인
- 없으면: 에이전트가 직접 수행 (또는 프로젝트 에이전트 생성 제안)
- 있으면: 오케스트레이션 모드
  - 사용자 지시 해석 → 프로젝트 에이전트에게 전달 (서브에이전트/Task 도구)
  - 프로젝트 에이전트가 실행 → 결과 반환
  - 에이전트가 결과 검토 → 사용자에게 보고

### 4.5 한 줄 부트스트래퍼

- 각 AI 플랫폼에 짧은 지시(3줄)만 삽입
- 부트스트래퍼가 `~/.opal/AGENT.md`를 Read로 읽어 에이전트 활성화
- 현재 100줄+ 스니핏 → 3줄 부트스트래퍼로 경량화

### 4.6 설치 방식

- git clone + `install-mac.sh` (기존 메뉴에 통합)
- 메뉴 [4] R2 알투 → OPAL AI Agent로 변경

## 5. 핵심 설계 결정

| 항목 | 결정 | 근거 |
|------|------|------|
| 프레임워크 이름 | OPAL | Open Protocol for Agentic Links |
| 에이전트 홈 | `~/.opal/` | 독립 디렉토리, 동기화 문제 없음 |
| 부트스트래퍼 | 3줄 지시 | 플랫폼 설정에 최소한만 삽입 |
| 정체성 저장 | `~/.opal/identity.md` | YAML frontmatter + markdown body |
| 오케스트레이션 | Task 도구 (서브에이전트) | 기존 task-flow-qa 패턴과 동일 |
| 프로젝트 에이전트 | `{프로젝트}/.opal/AGENT.md` | 기존 플랫폼 설정(.cursor/, .claude/)과 보완 관계 |
| 기존 스킬 | 각 플랫폼 디렉토리 유지 | OPAL 전용 스킬만 ~/.opal/skills/ |
| 마커 전환 | R2 → OPAL | `# === OPAL START ===` / `# === OPAL END ===` |

## 6. 범위

### 포함

- OPAL 소스 구조 설계 및 구현 (`templates/opal/`)
- AGENT.md, identity-template.md 작성
- 부트스트래퍼 3개 (Claude, Cursor, Antigravity)
- OPAL 전용 스킬 3개 (onboarding, project-init, orchestrator)
- 프로젝트 에이전트 템플릿
- `install-mac.sh` 수정 (install_r2 → install_opal)
- 기존 R2 파일 정리

### 제외

- curl 원라이너 설치 (향후 확장)
- AI 대화 기반 설치 (향후 확장)
- Windows/Linux 설치 스크립트

## 7. 제약사항

- 3개 AI 플랫폼(Claude Code, Cursor, Antigravity) 모두 호환
- 기존 task-flow, api-analyzer 등 스킬은 변경하지 않음
- `~/.opal/` 경로로 통일 (플랫폼별 복사 아님)
