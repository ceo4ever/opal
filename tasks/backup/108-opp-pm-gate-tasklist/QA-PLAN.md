# QA: PLAN — PM Gate 점검 목록 — TASK.md 요구사항 추가

> 검토일: 2026-04-11 | 판정: Pass

## 1. 요약

6개 파일럿 오케스트레이터 SKILL.md의 PM Gate 점검 목록에서 TASK.md가 누락된 구조 결함을 수정하는 계획이다. 각 파일의 PLAN-equivalent Phase 행(PLAN, PLAN+TEST-SCENARIO, SPEC, WIREFRAME)에 산출물과 체크리스트 위치 컬럼 모두에 TASK.md를 맨 앞에 추가하고, 변경이력 행을 삽입한다. 현재 상태(6개 파일 PM Gate 점검 목록)를 실제 파일에서 직접 확인하여 명세하였으며, 버전 번호도 실제 최신 버전과 일치함이 검증되었다. 모든 Step은 독립적으로 병렬 실행 가능하며, 변경 패턴이 일관되어 EXECUTE 단계에서 오류 가능성이 낮다.

## 3. 지적 사항

### Info: v1.9 -> v2.0 버전 전환

- **항목**: Step 6 opal-pilot-dev-wireframe 버전 채번
- **심각도**: Info
- **내용**: v1.9에 +0.1을 적용하면 v2.0이 된다. TASK.md의 "현재 버전 + 0.1" 규칙에 따른 결과이며 계산상 정확하다. 다만 v2.0은 의미상 major 버전 전환처럼 보일 수 있다. 해당 파일의 버전 체계가 단순 소수점 방식(v1.X → v2.X 자연 연속)을 따르고 있으므로, v2.0 채번은 적법하다. 진행에 영향 없음.

### Info: opsdd 체크리스트 위치 `-` 처리

- **항목**: Step 5 opal-pilot-sdd, Step 6 opal-pilot-dev-wireframe 체크리스트 위치
- **심각도**: Info
- **내용**: 두 파일의 현재 체크리스트 위치 값이 `-`로, 단순 추가가 아닌 교체가 필요하다. PLAN §2 핵심 설계에 "(기존 값이 `-`인 경우 `TASK.md 요구사항`으로 교체)"가 명시되어 있어 EXECUTE 단계에서 혼동 없이 처리 가능하다. 진행에 영향 없음.
